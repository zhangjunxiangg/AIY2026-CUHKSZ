## ⚡ 开拍前 60 秒

**手机设置（一次设好，别中途改）**
- [ ] **横屏 4K 30fps**——横屏给 deck 用，4K 是为了后期裁 9:16 竖版不掉画质（**不要为竖版单独再拍一遍，那是双倍机会成本**）
- [ ] **锁定曝光与对焦**（长按取景框出 AE/AF LOCK）——机械臂一动自动对焦就会来回拉风箱，整条废
- [ ] 关自动 HDR（会跳亮度）
- [ ] 存储余量 > 5GB

**环境**
- [ ] **光在镜头背后**，别逆光（赛场顶灯硬，逆光机器人全黑）
- [ ] 手机架三脚架 / 垫一摞书，**别手持**
- [ ] 背景里**不要有走动的人**——机位压低、贴近，把画面填满就能挡掉大半
- [ ] 道具按 V3 §12 摆放：贴标签的标准道具，**尺寸预先量好**（明面 + 桌下盲区各布几件）

**⛔ 拍摄时全程不说话**——只有镜①那句口头规则要出声。其余任何解说都会毁掉音床，后期配音会很难救。

## 🎬 七个镜头

> **每条都让机器人跑够目标时长的 3–4 倍**——机械臂慢，后期要提速，素材短了没法剪。

### ① 口头下规则 ｜目标 8s ｜⭐️ 收音最关键
- **画面**：中近景，你（或保育员角色）对着机器人说话，手机距嘴 30–50cm
- **台词（V3 §6-③ 冻结原文，一字不改）**：
  > 「今天托小班有个 1 岁半的新生，所有能塞进嘴的都按红色处理。」
- **收音**：赛场很吵。**当场再单独录一条干净人声备份**（见下面「必须单独录的音频」）
- **成功判据**：这句话在回放里能听清每个字
- **退路**：听不清 → 后期用干净 VO 覆盖，画面保留

### ② 出发 / 巡视 ｜目标 8s
- **画面**：低机位（贴地 10–15cm），机器人从画面一侧驶入或驶离，让轮子和地面占前景
- **注意**：底盘 ≤0.20 m/s，动作本来就慢——**拍 30s 素材，剪成 8s**
- **退路**：无（这条最好拍）

### ③ 哨兵发现盲区物 ｜目标 10s
- **画面**：辅助板（架高侧位 Gemini 335）的视角，或它看到的画面
- **最省事的做法**：**板端截图 / 屏幕录制**，比架机位拍屏幕清楚得多
- **要点**：画面里要能看出"这个东西在桌子底下，贴地视角看不见"
- **退路**：拍不到 → 用 CHART-04 时序图 + 一张盲区照片代替

### ④ 靠近 + 臂下探 + 夹取 ｜目标 25s ｜⭐️ 全片核心
- **画面**：**侧机位、贴地、离机器人 40–60cm**，让机械臂的下探轨迹完整入画（别拍成俯视，俯视看不出"探到地面"这个动作）
- **构图**：夹爪和目标物**都要在画面里**，别让机身挡住夹取瞬间
- **一定要拍到**：夹爪闭合的那一刻 + 抬起来物体确实在夹爪里
- **时长**：让它跑完整流程，**素材可能 90–120s，剪成 25s 并提速**
- **成功判据**：外行看一遍就知道"它把地上那个东西夹起来了"
- **退路**：夹取不稳 → 多拍几次取最好一条；**实在夹不起来就拍"下探到位 + 夹爪闭合"，配字幕说明负载边界**（V3 §12 允许诚实降级，别演假的）

### ⑤ 分盒 ｜目标 8s
- **画面**：夹爪把物体投入标了「红/黄/绿」的盒子
- **退路**：拍一张静态照片，剪辑里当定格用

### ⑥ 手机端日志 ｜目标 12s
- **画面**：手机屏幕上的结构化记录，**要能看清时间戳和判定等级**
- **屏幕拍摄**：手机拍手机会有摩尔纹和反光 → **优先直接屏幕录制**
- **内容对齐 V3 §6-④**：
  ```
  14:32 | 活动室东南角地垫边缘 | 圆形金属物 φ≈20mm | 判定红色 | 已夹取至危险品盒 | 照片存档
  ```
- **加分**：如果能同时录到 M-Claw 的推理输出文本，**单独再录一条**——那是"AI 用在哪个环节"的最直接答案

### ⑦ 急停 ｜目标 10s ｜安全 10 分素材
- **画面**：机器人在动 → 触发急停 → **立刻静止**。要在同一个镜头里连续拍完，别切
- **要点**：让"动"和"停"的对比明显；能拍到手按下去的动作更好
- **退路**：无（这条最容易拍，30 秒搞定）

## 🎙 必须单独录的音频（拍完立刻录，别拖）

赛场噪音会让同期声不可用，所以另录三条干净音轨：

1. **口头规则那句**——找个安静角落，手机备忘录录 3 遍取最好的

3. **环境静音样本 5 秒**——给 ffmpeg 做降噪的噪声基准
