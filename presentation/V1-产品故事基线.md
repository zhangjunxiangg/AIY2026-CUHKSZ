## 0. 一句话

> **地上那些小东西，对一个 2 岁的孩子和一个 80 岁的老人，都是致命的。我们做一台在他们不在场时把地面风险挑走、并留下记录的机器人。**

落到具体产品：

- **托育版**：孩子进屋前 / 午睡时，它把地上"能被塞进嘴里"的东西挑走，并留一份带时间和照片的记录。
- **养老版**：老人起夜前 / 不在房间时，它把地上"会被绊到、或者需要弯腰去捡"的东西清掉，并标出反复出问题的区域。

## 1. 故事内核：为什么是"地面"

这是整个故事最硬的一句话，两条数据来自两个独立的官方口径：

| 人生的一端 | 伤害死亡的**首位**原因 | 数据 |
|---|---|---|
| 5 岁以下儿童 | **气道异物** | 2017 年全国 6896 例，死亡率 8.57/10 万；80% 发生在 3 岁以下，1–2 岁最集中 |
| 65 岁以上老人 | **跌倒** | 死亡发生率 58.03/10 万；社区老人年跌倒率 14.7%，其中 79.5% 受伤；一半以上发生在家中（56.41%） |

**人生两端的头号杀手，都在离地 0–20 厘米的高度。**
而今天所有在这个高度作业的机器人（扫地机、商用清洁机器人），解决的都是"**干净**"，没有一台在解决"**危险**"。

这就是我们要占的位置。

## 2. 两个市场

### 2.1 A 线 · 托育 / 幼儿园（演示主线）

**场景**：孩子午睡时，保育员必须守在寝室；活动室的地面在这段时间是无人看管的。等孩子醒来回到活动室，地上任何东西都会先进嘴。

**痛点链**（P2/P3 已有，此处升级表述）：
1. 保育员"顾得了地面就顾不了孩子"——10 分钟内注意力切换 7 次/分钟
2. 致梗物就是地上最常见的东西：**花生米、瓜子、豆类、笔帽、口哨、玩具零件**；3 岁以下孩子的气道**只有铅笔粗细**
3. **纽扣电池**：贴上食管 15–30 分钟开始灼伤，超过 6 小时可致穿孔。一项 24 例临床研究里，**7 例家长根本不知道孩子吞了东西**——没有目击史，就没有时间线，既没法抢救也没法追责

**市场**：
- 托育机构 **11.4 万家**（2024 年底，+13.8%），托位 573.7 万，入托 262.6 万人
- 从业人员 126.5 万，其中保育人员 63.0 万；**行业人才缺口近 100 万人**
- 婴幼儿托育市场 2024 年 **1518.1 亿元 → 2030 年预计 2323.1 亿元**
- 幼儿园 25.33 万所（但一年减少 2 万多所，少子化冲击中）
- 备案率低：2024 年备案在托规模仅占 **25.91%**，未备案 74.09%

**政策窗口**：《全国托育服务质量提升行动（2025–2027 年）》，新增 66 万普惠托位，强调标准化建设——**整改压力就是采购动机**。

### 2.2 B 线 · 养老（roadmap 主线，也是更大的市场）

**场景**：老人在客厅/卧室活动，地上掉了东西。两个独立的痛点叠加：

1. **看不清**——60 岁以上白内障发病率约 80%（约 2 亿人）；低视力群体约 500 万，其中 60 岁以上占 67%；52 岁后老花发病率接近 100%。**东西掉在地上，他不知道**。
2. **弯腰这个动作本身就是事故**——跌倒是 65 岁+伤害死亡首位原因；髋部骨折每年新发**超 100 万例**，1 年死亡率 20%–30%，约 35% 的幸存者再也无法独立行走，被称为"人生最后一次骨折"。

> ⚠️ **诚实标注**：公开监测体系按"跌倒"和受伤部位分类，**没有"弯腰捡东西导致闪腰/跌倒"的独立统计**。这一环是我们的合理推断，PPT 里必须表述为"弯腰是老人跌倒的常见诱发动作"，不能编造百分比。若要坐实，需要现场访谈养老机构护理员补一条一手证据（和 A 线的 22/47 观察同性质）。

**市场**：
- 2025 年 2 月，**中国主导制定的全球首个养老机器人国际标准**发布；业界称 2026 为"养老机器人元年"
- 2026 Q1 具身智能领域披露融资超 50 起、约 200 亿元，同比增长近六成
- 3.2 亿老年人口

**为什么 B 线比 A 线更值钱**：托育受出生人口下滑压制（幼儿园一年关掉 2 万所），是存量竞争；养老是单边上行。**A 线做演示（情感冲击强、道具好搭），B 线做 roadmap（市场大、政策顺）**——这正好把"可扩展性 10 分"落到实处。

### 2.3 为什么它们是同一个产品

| | 托育 | 养老 |
|---|---|---|
| 地上的东西 | 会进嘴 | 会绊倒 / 需要弯腰去捡 |
| 谁看不见 | 保育员被孩子占住注意力 | 老人视力退化 |
| 危险标准由谁定 | 今天班里最小的孩子月龄 | 这位老人的身体状况 |
| 机器人在什么时候干活 | 孩子不在场（午睡/入班前） | 老人不在场（起夜前/白天外出） |
| 产出 | 班级安全日志 | 风险区域记录 |

**同一套软件、同一套硬件、同一条任务链，换一份自然语言的判定规则。** 这句话本身就是产品的技术护城河描述。

## 3. 竞品地图

### 3.1 竞品是谁

**第一梯队 —— 长出手的家用扫地机（最接近，也最危险的对手）**

| 玩家 | 已经做到什么 |
|---|---|
| **石头 Saros Z70**（CES 2025） | 全球首款带机械臂的扫地机。五轴可折叠 **OmniGrip**，内置摄像头 + LED 识别、传感器检测物体重量和位置。能捡袜子、纸巾、小毛巾。AI 可识别数百种物体并分类投放：垃圾进垃圾桶、玩具进玩具箱、袜子进脏衣篮、鞋子摆门口。**已公开的短板：机械臂操作速度慢** |
| **追觅 Dreame** | CES 2025 首创仿生多关节机械手，能夹起玩具放进杂物柜；机械臂系列产品销量**破 200 万台**（截至 2024-12）；X50 Ultra 仿生机械足 6cm 越障；2026 CES 展出会爬楼的 Cyber X |
| 行业体量 | 2025 前三季度全球扫地机出货 1742.4 万台，**前五名全是中国厂商**（石头、科沃斯、追觅、小米、云鲸）；2024 中国清洁电器销售额 423 亿元，+24.4% |

**第二梯队 —— 商用清洁机器人**

- **高仙 Gausium**：清洁赛道专精，6 大系列，覆盖写字楼/商超/酒店/医院/工厂
- **普渡 Pudu CC1**：60+ 国家，CC1 累计出货超 2 万台（截至 2025），欧美占 60%
- 经济模型：5000㎡ 商场投资回收期 1–2 年，一台替代 2–3 名保洁

**第三梯队 —— 养老/助老机器人（B 线的对手）**

- **星尘智能 Astribot S1**：已进驻深圳养老院做真实场景训练（叠衣服），提供了行业首个高质量养老实景数据
- **光谷东智 Lumen S1**：面向机构养老的人形机器人，"1+1+N" 方案，覆盖安全巡检/陪伴/健康管理/生活照料
- **傅利叶智能**：首个落地场景是康复训练
- 现状：抓取、摆放、叠衣**主要还在展会和试点阶段**；真正规模化落地的仍是巡检、陪伴、康复助行

**第零梯队 —— 现在实际在用的方案（这才是真正的对手）**

肉眼扫视 + 手动拖擦 + 保育员的注意力。以及一张纸质安全检查表。

### 3.2 他们现在怎么解决这个问题

**答案是：他们没有在解决这个问题，他们在解决另一个问题。**

| 玩家 | 它认为地上的小东西是什么 | 它的处理动作 |
|---|---|---|
| 普通扫地机 | **要么吸走、要么绕开的障碍** | 吸进尘盒（纽扣电池会被吸进机器肚子里），或 AI 避障绕过去 |
| 石头 Z70 / 追觅 | **挡路的、清完要归位的杂物** | 标记位置 → 移到已清洁区 → 扫完再放回原处 |
| 商用清洁机器人 | 不在它的问题域 | 只处理"地面上体积较小的垃圾"，易拉罐、水瓶、口香糖都处理不了 |
| 养老机器人 | 不在它的问题域 | 主打陪伴、巡检、康复助行 |
| 现有人工方案 | 危险物 | 靠人**看到**——而这正好是失效的环节 |

关键差别一句话：**它们把地上的东西当"清洁对象"或"通行障碍"，没有人把它当"风险证据"。**

### 3.3 为什么大多数竞品没有加入这个功能

六条原因，从硬到软：

**① 产品逻辑天生相反：机械臂是为了"清路"，不是为了"取证"。**
石头 Z70 的完整逻辑是"标记可移动物品 → 移开 → 扫地 → 归位"，目的是**让自己能扫完这块地**。所以它会把纽扣电池当垃圾丢进垃圾桶——动作看着一样，语义完全不同：我们要的是**挑出来、分级、留证、通知人**。归位甚至是有害的（把危险物放回原处）。

**② 经济模型不匹配——这条最硬。**
商用清洁的 ROI 公式是「替代保洁人工 × 大面积」：5000㎡ 商场 1–2 年回本。托育机构一间活动室百十平米，**面积不够，人工替代账算不出来**。物业从业者的真实反馈是小面积场景"非常鸡肋"，而且**地面场景只占整体清洁需求的 20%，80% 是立体清洁**。所以清洁厂商的销售漏斗天然把幼儿园和养老院过滤掉了。
> **反推我们的定价逻辑**：我们卖的不是"替代人工"，是"替代风险"。锚点不是保洁工资，是一次误吞事故的赔偿 + 停业整顿 + 招生口碑。这是一笔完全不同的账，也是我们能在小面积场景成立的唯一理由。

**③ "危险"无法固化进 SKU。**
扫地机是标准化消费品，一款卖几百万台，AI 识别的是**固定的数百种类别表**。但危险标准在托育里随月龄和班型变（国标乳儿班 1:3 / 托小班 1:5 / 托大班 1:7），在养老里随这位老人的身体状况变。这是**运营知识，不是产品参数**——在 LLM 之前，工程上没法做。
**这是我们唯一真实的技术窗口，也是整个故事必须站在这一点上的原因。**

**④ 责任与合规风险，大厂主动回避。**
幼儿和失能老人是弱势用户，机器人与他们同场作业一旦出事，是消费品牌承受不起的公关风险。风控会直接砍掉这个场景。养老机器人的国际标准 2025 年 2 月才刚发布，说明规范本身也才起步。
> **反推我们的设计**：把"不与被照护者同场作业"做成**产品特性**而不是免责条款——机器人只在孩子午睡、老人不在房间时工作。这一刀同时解决合规、演示环境和评委的第一质疑。

**⑤ 没有 B 端责任链的产品形态。**
扫地机 App 给家庭用户看清扫报告，没有"交接班 / 责任人 / 可举证日志"这套东西，因为它不提升复购。但这恰恰是机构付钱的真正理由——托育备案率仅 25.91%，质量提升行动正在压整改。

**⑥ "地面起伏"根本不在它们的问题域里。**
这条是你提的，很关键。扫地机对高低差的定义是"**我能不能过去**"——追觅 6cm 越障、石头 G-Rover 爬楼，全是**通行能力**。而托育和养老关心的是"**这个翘边的地垫会不会绊倒人**"。同一个深度相机读数，两种完全相反的语义。
**没有任何一家把高低差数据用于人的绊倒风险评估。这是一块真空。** 而我们有深度相机，这件事技术上不难，故事上极亮。

## 4. 差异化：三个只有 LLM 时代才成立的设计

自检标准（来自 `docs/选题方向与场景策略研究.md`）：**把 LLM 删掉，它还成立吗？**

**① 危险标准当天用自然语言口头交代，不写死在代码里。**
"今天托小班有个 1 岁半的新生，所有能塞进嘴的都算红色。"→ 同一个物体，处置等级立刻从黄变红，动作和播报跟着变。
养老版："张阿姨昨天刚做完白内障手术，今天所有反光的、深色的小东西都按红色处理。"
**检测器做不到（类别表写死）。这是全案的记忆点，也是现场最容易出效果的 15 秒。**

**② 双设备"哨兵 + 执勤员"的意图流转（软总线）。**
- 辅助板（Gemini 335，架高侧位）= **哨兵**，专看盲区：桌下、墙角、机器人自己身体挡住的地方
- 小车板（Astra + 5DOF 臂 + 夹爪）= **执勤员**，过去、判断、夹走
- 软总线 = **对讲机**：发现 → 通报坐标 → 接单 → 处置 → 回报 → 生成日志

队友已实现的 `src/perception/fusion_node.py`（双相机融合、盲区优先用辅助相机）就是这段的代码实体。
**"盲区"这个词也从"清洁盲区"升级成"照护盲区"**，和保育员那句"眼睛不敢离开孩子"扣死。

**③ 可举证的自然语言日志。**
不是"检测到物体 ID 7"，是"14:32，活动室东南角地垫边缘发现一枚圆形金属物，判定红色，已夹取至危险品盒，照片存档"。
这段话既是给园长的免责证据，也是给评委的"AI 在哪个环节起作用"的直接答案。

## 5. 商业模型

**谁付钱**：不是保育员/护理员，是**机构管理者**（园长 / 养老院院长）。

**买的三件事**：

| | 买点 | 支撑 |
|---|---|---|
| 免责 | 每日安全日志，家长/家属纠纷时可回溯 | 纽扣电池研究中 7/24 例家长不知道孩子吞了东西 |
| 合规 | 应对质量提升行动的整改与备案压力 | 备案在托仅占 25.91% |
| 招生 | "我们每天两次 AI 地面安检，有记录" | 幼儿园一年关掉 2 万所，存量竞争下安全是最贵的差异化 |

**成本锚（必须说清）**：

- 一线托育老师税后 6000–7000 元/月；具备基础护理功能的养老机器人售价 8–15 万元 ≈ 一名护工 2–3 年工资
- 所以口径必须是：**它不替代人，它替代的是"人做不到的那一遍"**——一个人不可能低头 22 次还保证不漏掉一颗花生米，一个 80 岁老人不可能既看得清地面又能安全弯腰

**扩张路径**：托育班 → 幼儿园（3–6 岁）→ 养老机构 → 居家养老 → 母婴室 / 儿童乐园 / 月子中心。
硬件侧：驭系列本身是多形态家族（移动机器人 / 四足 / 无人机），同一套语义规则可迁移——这是"可扩展性"的现成答案。

## 6. 与现场 demo 的对应关系（诚实边界）

| 故事里的动作 | 现场实际做什么 | 状态 |
|---|---|---|
| 巡视地面 | 底盘按点位移动（`/cmd_vel`，≤0.20 m/s） | 可做 |
| 认出地上的东西 | HSV 颜色+形状 / 模板匹配 / QR 解码 | 可做，**非开放词汇神经检测** |
| 看见盲区 | 双相机融合，盲区优先用辅助板相机 | 队友已实现 |
| 判断危险等级 | M-Claw 按当天口头规则推理 | **核心，必须跑通** |
| 夹走 | 5DOF 臂 + 夹爪（ID10，250–800） | 可做，轻小物体 |
| 地面起伏 | 深度相机读高低差 | **待验证，是加分项不是必做项** |
| 生成日志 | 时间 + 类别 + 照片 + 处置结果 | 可做 |

**必须在 PPT 里写明的一句**：现场用标准道具替代真实危险物（贴标签的色块/圆片代表纽扣电池、花生等）。官方规则明确允许合理模拟与降级演示，**主动说明扣的分远少于被评委问穿**。

**推荐的诚实分工**：道具上的标签/QR 给出"这是什么"，M-Claw 负责"**它对今天这个班/这位老人危险吗**"。识别交给标签，判断交给模型——分工诚实，且正好把 LLM 放在唯一不可替代的位置。

## 7. 红线

1. **不得做医疗诊断**。赛事规则明令。口径只能是"物理危险物的识别、清除与记录"，**不能说"预防窒息""降低跌倒死亡率"**。6896 例、58.03/10 万这类数据作为**场景价值背书**引用是安全的，但不能宣称产品能改变这些数字。PPT 需有一句免责声明。
2. **不得声称机器人可与幼儿/失能老人同场作业**。这是产品设计的边界，也是我们的卖点。
3. **隐私**：涉及儿童/老人环境图像，PPT 与文档需声明"仅用于本次比赛演示，不存储真实环境数据"。
4. **竞品数据进 PPT 前逐条核实**（尤其出货量、售价、回本周期），写错比不写伤害大。
