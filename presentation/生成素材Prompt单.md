# 生成素材 Prompt 单（即梦 Web 端 · 可直接复制）

> **口径依据**：`V3-路演口径基线.md` §11 视觉红线 / §13 视觉规范
> **用法**：浏览器开即梦，对着本页复制。**先出图，再拿图去生视频**——动画一张已确认的静图，比文生视频可控得多。
> **落盘**：图 → `presentation/assets/scenes/` ｜视频 → `presentation/assets/broll/`
> **命名**：`IMG-01-花生米-v1.png` / `VID-B01-地面推进-v1.mp4`（版本号方便对比取优）

---

## ⛔ 三条红线（每张生成图都要过一遍）

1. **画面里绝不能有儿童，也不能有机器人与儿童同框**——出现一次就当场推翻 V3 §3「只在孩子不在场时作业」和 §8 的竞品差异论证。评委会立刻看出核心论点自相矛盾。
2. **不出现任何可识别的人物面部**。标准画面是**空活动室**。
3. **机器人的动作不做 AI 视频**。机械臂在 AI 视频里一定物理错乱（关节数不对、夹爪形变、抓取违反物理），这是机器人赛道，评委认得出，反而砸可信度。**机器人动作一律实拍（VID-01 分镜单）。**

> 想要"机器人产品级运镜"的话，安全做法是：拿现成的白底渲染图，用 ffmpeg 做慢推/慢移（Ken Burns）。零 AI、零结构失真，我在剪辑阶段直接做，不用你操作。

---

## 第一步 · 通道确认（3 分钟）

普通会员没有 CLI 权限，所以全部走 Web 端。先确认三件事再批量生成：

- [ ] 图片生成能正常出图（先跑 IMG-01）
- [ ] **确认一次生成消耗多少积分**，以及你的会员每日/每月额度
- [ ] 确认能不能用「图生视频」——普通会员的视频权限可能也受限。**如果视频也不可用，立刻告诉我，我把方案切成"静图 + ffmpeg 运镜"**，效果不差且完全不依赖额度

```
超低机位微距摄影，相机贴近地面约15厘米高度，浅景深大光圈。画面正中前景是一颗花生米，静静躺在浅米色软质拼接地垫的接缝凹槽里，花生表皮纹理清晰锐利；中远景是虚化的幼儿园活动室——浅木色矮桌腿、矮玩具收纳架的一角。下午四点的暖阳从右侧窗户斜射进来，在地垫上投下百叶窗的长条形阴影。空间里空无一人，安静克制略带压迫感。纪实摄影风格，自然光，真实材质质感，高细节。
```

**用途**：技术主轴（双机位为什么必要）+ AB 实验那句「多出来的 3 件全在桌子底下」
**比例**：3:2

```
低机位摄影，相机贴近地面，从地面高度看向一张幼儿园浅木色矮桌的桌底空间。桌下是一片阴影区，阴影深处躺着一个很小的浅色圆形物体，几乎被暗部吞没、极不易察觉。画面右上角有从窗户斜射进来的暖光，但光线照不进桌下。浅景深，焦点落在那个小物体上。空无一人。纪实摄影，暗部细节丰富，冷静克制。
```

**验收**：那个小物体要**若隐若现**——太明显就丧失了"人看不见"的说服力，太暗则观众找不到。理想是"被指出来才注意到"

# B · 视频（图生视频，4 条）

**前提**：先拿到上面的图，用它当**首帧**再生视频。不要用文生视频——构图不可控，且容易生出人。

**Web 端通用设置**：功能选**图生视频**；时长 **5 秒**（够用，也省额度）；比例跟随输入图；清晰度 720p 起。

**这些视频的用途**：**不是独立宣传片**，而是 **V1 实拍视频的片头与转场 B-roll**。V1 需要一个"先讲问题、再出机器人"的冷开场，而赛场地面不是幼儿园——这正是 AI 视频该补的位，也是它唯一该补的位。

**即梦生视频的四种常见翻车**（所以每条 prompt 都在压制运动）：
① 自作主张加运镜抖动 ② 物体漂移或形变 ③ 凭空生出人或手 ④ 光影闪烁跳变
→ 每条建议**生 2 次取优**。

## VID-B01 · 地面视角推进 ⭐ V1 的冷开场

**首帧**：IMG-01（花生米）或 IMG-02（纽扣电池）
**用途**：V1 片头 0–5 秒，先把"危险就在离地几厘米处"钉住，机器人还没出场

```
镜头极缓慢向前匀速推进，轻微靠近地垫上的物体，景深逐渐变浅。物体本身完全静止不动，不滚动不位移不变形。背景虚化的活动室保持静止，家具不移动不变形。窗外斜光稳定，地面光影几乎不变。除镜头推进外，画面没有任何其他运动。安静、克制、略带压迫感。全程无人物出现。
```

**验收**：物体没有滚动/漂移；没有凭空出现的手或人；没有画面抖动

## VID-B02 · 空活动室缓慢横移

**首帧**：IMG-04（空活动室）
**用途**：场景转场；暗示"这 1–2 小时，这个房间没人看着"

```
镜头极缓慢向右匀速横移，轨道运镜般平稳，扫过空无一人的幼儿园活动室。桌椅、玩具收纳架完全静止，不移动不变形。空气中有极细微的浮尘在斜射的阳光里缓慢飘动。窗外光线保持稳定不闪烁。画面安静、整齐、略带空旷感。全程没有任何人物出现，没有人影走动。
```

**验收**：家具在移动过程中**不变形**（这是横移最容易崩的地方）；确实没有人影

**首帧**：IMG-05（桌下盲区）
**用途**：技术段——引出"为什么需要第二个机位"

```
镜头极缓慢向前低位推进，探向矮桌下方的阴影区，逐渐靠近阴影里那个很小的浅色物体，焦点始终锁定在它上面。物体完全静止不动。桌子、地面保持静止不变形。右上角斜射的光线稳定不闪烁。除镜头推进外画面无其他运动。氛围安静、隐蔽、略带不安。全程无人物出现。
```

**验收**：推进过程中桌子腿不弯折变形；焦点没有跑掉
