## 核心论点

现有方案不是解决不了这个痛点，是**没法证明自己解决了**。

行业没人做这件事，归结为两点：

1. **责任很难划分** —— 出事了算谁的？机器人厂商不敢接，机构也不敢信
2. **收益很难量化** —— 省了多少钱？孩子安全提高了多少？没有任何一个数字能回答

这两点其实是同一件事的两面：**因为收益无法量化，所以没人愿意为一个说不清的责任买单。**

所以本产品真正的创新不在"能捡东西"（石头 Z70 在 2025 年初就量产了机械臂），而在：

> **把"地面对婴幼儿的危险程度"这件事，第一次变成一个有单位、可记录、可对比的量。**

量化出来之后，责任才能被切分，收益才能被计算，这个市场才成立。

## 一、在什么场景

**空间**：托育机构 / 幼儿园的**活动室**（不是寝室）。
特征：小面积、多隔间、软质拼接地垫、低矮家具多。**这几个特征正是商用清洁机器人进不来的原因**（见第五部分）。

**时间窗**：**午睡时段**（备选：入班前）。

孩子在寝室午睡，保育员必须在旁值守；活动室在这 1–2 小时里空着、且无人看管。等孩子醒来回到活动室，地上任何东西都会先进嘴。

**机器人只在孩子不在场时作业。** 这一条同时解决四件事：

| | 解决什么 |
|---|---|
| 合规 | 不与幼儿同场作业。评委问"机器人在孩子旁边动安不安全"，答案是"它设计上永远不会" |
| 演示 | 现场本来就是空场，演示环境与真实场景一致 |
| 商业 | 它变成**交接班的一道工序**——有 SOP、有责任人、有时间戳 |
| 人力 | 这个时段保育员的注意力被寝室占满，正是最需要一双手的时候 |

**触发**：保育员进寝室前口头交代当天规则 → 机器人作业 → 完成后日志推到她手机。

## 二、给谁用

必须分清"谁操作"和"谁付钱"。

| 角色 | 是谁 | 关键约束 |
|---|---|---|
| **操作者** | 保育员 / 保育老师 | 说一句话、看一眼手机。**不能增加任何操作负担**，否则一定被弃用 |
| **付费决策者** | **园长 / 机构负责人** | 见下 |
| 受益者 | 2–3 岁婴幼儿 | 间接 |
| 影响者 | 家长 | 招生端 + 纠纷端 |

**决策者是园长，这有法定依据**：

- 《上海市托育机构设置标准》——**托育机构负责人是机构安全和卫生保健工作的第一责任人**，机构应"执行日巡查制度，做好安全巡查记录，及时消除安全隐患"
- 国家《托育机构管理规范（试行）》第 22 条——建立**照护服务日常记录和反馈制度**

> **这条很重要**："每天巡查地面并留记录"不是我们发明的新需求，是**法规压在园长个人头上的义务**，现在靠手工填表完成。我们卖的是把这项已强制的义务自动化，并且变成可举证的证据。

## 三、解决什么问题 / 没有它会怎样

### 3.1 问题分三层

**第一层 · 注意力不可分割**
现场观察：10 分钟内保育员低头看地 22 次、抬头看孩子 47 次，切换 **7 次/分钟**。（团队一手观察数据，全案最值钱的原创素材）

**第二层 · 人眼的物理极限**
致梗物是地上最普通的东西：花生米、瓜子、豆类、笔帽、口哨、玩具零件。3 岁以下孩子的气道**只有铅笔粗细**。再加上桌下、墙角这些蹲下才看得见的盲区——**这不是保育员不认真，是人做不到**。

**第三层 · 没有证据（商业核心）**

出事之后的法律机制是**过错推定 + 举证责任倒置**：《民法典》第 1199 条——无民事行为能力人在幼儿园受到人身损害，**先推定机构有过错**，机构**能证明尽到教育、管理职责的才不承担责任**。且法律上的"意外"指不可抗力，不是"没想到"；**异物窒息属于典型可预见风险，以"意外"免责通常不成立**。

**园方唯一的免责路径是证明自己排查过。而他手上只有一张事后补填的纸质巡查表。**

### 3.2 没有这个产品会怎样

| 层级 | 后果 |
|---|---|
| 日常 | 保育员长期高认知负荷；日巡查记录沦为形式；地面盲区从未被真正检查 |
| 家长端 | 安全与环境设施是家长对托育不满意的主要因素之一，构成招生阻力 |
| 事故 | 气道异物是 **5 岁以下儿童伤害死亡首位原因**（2017 年全国 6896 例，80% 发生在 3 岁以下）；纽扣电池贴上食管 **15–30 分钟开始灼伤，超 6 小时可致穿孔**；24 例临床研究中 **7 例家长根本不知道孩子吞了东西** |
| 事故之后 | 举证责任倒置 → 证明不了尽责 → 判赔（公开判例 1.6 万 / 2.37 万，涉伤残案诉求 11.04 万），另有独立的行政责任线与声誉损失 |

**一句话**：园长面对的不是"地面不够干净"，而是**一个他无法证明自己尽责的风险敞口**。

## 四、技术方案与技术优势

### 4.1 方案四层

**① 双机位感知（软总线，对应评分 25 分最大单项）**

- 辅助板 Gemini 335，架高侧位 = **哨兵**，专看盲区（桌下、墙角、机器人自身遮挡区）
- 小车板 Astra + 5DOF 臂 + 夹爪 = **执勤员**，过去、判断、夹走
- 软总线 = **对讲机**：发现 → 通报坐标 → 接单 → 处置 → 回报 → 出日志
- 代码实体：队友已实现 `perception/fusion_node.py`（双相机融合、盲区优先用辅助相机）

**② 危险判据国标化 —— 本方案的技术主轴**

**GB 6675.2-2014《玩具安全 第2部分：机械与物理性能》**：36 个月以下玩具**严禁含可通过"小零件试验器"（内径 ≤ 31.7 mm）的部件**——零件能完全落进该量筒，即判定存在吞咽/窒息危险。

**这把"能被塞进嘴里"从一句感性描述，变成了一个 31.7 毫米的国家强制标准阈值。**

三个好处：

1. **客观**：不是我们拍脑袋定的红黄绿，是强标背书，客户和评委都无法反驳
2. **可测**：31.7mm 是深度相机 + 视觉能估算的物理量；且该阈值对应的正是**极贴近地面的小物体**——恰好是人蹲下才看得见、而机器人视角天然占优的那一类
3. **月龄分级有标准依据**：新版 **GB 6675-2025 按 0–18 / 18–36 / 36–96 个月三级差异化要求，低龄更严**。**"危险随月龄变"不是我们编的产品逻辑，是国标本身的逻辑**

**③ M-Claw 语义分级（LLM 不可删除性）**

判定 = **国标尺寸阈值（客观）× 当天口头规则（运行时可变）**

> "今天托小班有个 1 岁半的新生，所有能塞进嘴的都按红色处理。"
> → 同一个物体，等级立刻从黄变红，动作和播报跟着变。

自检：把 LLM 删掉——尺寸阈值还在，但"随当天在场儿童动态调整判定"这件事整个消失。**删不掉。**

**④ 物理清除 + 可举证日志**

夹走 → 分盒（红：立即通知；黄：待检；绿：留给常规清扫）→ 生成结构化记录：
`14:32 | 活动室东南角地垫边缘 | 圆形金属物 φ≈20mm | 判定红色 | 已夹取至危险品盒 | 照片存档`

### 4.2 技术优势四条

| 优势 | 为什么别人做不到 |
|---|---|
| 判据是国标，不是主观分级 | 31.7mm 有强制标准背书 |
| 规则运行时可改，不烧进模型 | 检测器类别表写死；这在 LLM 之前工程上做不了 |
| 双机位覆盖照护盲区 | 单台家用机器人视角贴地，桌下墙角是其结构性盲区 |
| 输出是证据链，不是清洁报告 | 时间戳 + 照片 + 尺寸 + 处置 + 责任人，直接对接举证责任倒置这一法律机制 |

**第三档 · 真正的对手**

保育员的肉眼 + 一张手工巡查表。

### 5.3 他们现在怎么解决

**他们没在解决这个问题，他们在解决另一个问题。**

| 玩家 | 它眼里地上的小东西是什么 | 动作 |
|---|---|---|
| 普通扫地机 | 要吸走或绕开的**障碍** | 吸进尘盒（纽扣电池被吸进机器肚子）或避障绕开 |
| 石头 Z70 / 追觅 | 挡路的、清完要**归位**的杂物 | 标记 → 移开 → 扫地 → **放回原处**（对危险物而言，归位是有害的） |
| 商用清洁 | 不在问题域 | 只处理小体积垃圾，易拉罐、口香糖都处理不了 |

**没有人把地上的东西当"风险证据"。**

## 六、为什么没人做：责任 + 量化

### 6.1 责任很难划分

机器人清过一遍之后孩子还是误吞了，算谁的？

- 厂商不敢接：等于对儿童生命安全做出承诺
- 机构不敢信：买了之后如果反而被认为"你有设备还出事"，责任更重
- 结果：双方都退回到现状——**谁都不碰，宁可继续用肉眼**

**旁证**：石头给机械臂配童锁并默认关闭，就是龙头企业在这条逻辑下的选择。

### 6.2 收益很难量化

园长要批预算，必须回答"这台机器换来了什么"。而现在**一个数字都给不出来**：

- 省了多少人工？——保育员该在的还得在，配比是国标刚性（1:3 / 1:5 / 1:7），一个人都减不掉
- 孩子安全提高了多少？——没有基线。**今天地上到底有几件可吞入物？没人知道，因为从来没有人数过**
- 避免了多少损失？——事故是小概率事件，没发生的事故无法计价

**没有基线，就没有改善；没有改善，就没有预算。** 这才是这个市场至今是空白的真正原因——不是技术不够，是**这件事从来没有被测量过**。

## 七、我们的破法：把两件事都变成可量化的

### 7.1 责任的破法：不承担模糊全责，只承担一个窄到可验证的责任

**不做的事**：不承诺"保证孩子不误吞"。这是无法兑现的，也是所有厂商退缩的地方。

**做的事**：把责任切成一个有明确边界的**时间切片**。

```
责任边界声明（写进产品，也写进 PPT）：
  作用范围：活动室地面
  作用时间：14:00–14:20 的作业窗口
  作用对象：地面可见的、最长边 ≤ 31.7mm 的物体
  产出：该窗口内的完整排查记录（时间 + 位置 + 尺寸 + 照片 + 处置）
  不负责：窗口之外、非地面、遮挡物之下、尺寸超限
```

**为什么这样反而解开了死结**：

- 对机构：它不接管你的责任，它**给你一份你原本拿不出的证据**——直接对应举证责任倒置这一法律机制下唯一的免责路径
- 对厂商：责任被限定在"我是否在这个窗口内完成了这次排查"，这是可验证、可复现、可担保的
- **明确边界本身就是责任划分。** 行业做不了是因为责任模糊，我们的破法不是承担更多责任，而是**把责任切得足够窄，窄到可以被验证**

> ⚠️ 表述红线：只能说"提供排查记录/证据材料"，**不得承诺任何法律效果**（不能说"帮您免责"）。

### 7.2 收益的破法：造一个从来不存在的指标

**核心指标 · 可吞入物暴露时长（Ingestible Exposure Time, IET）**

> 定义：一件符合 GB 6675 小零件判据（≤31.7mm）的物体，从落到地面到被清除之间的时长。

现在这个数字是**未知**——可能是几小时，直到有人偶然发现，或者孩子先发现了。
有了机器人，它的**上限被硬性压到"两次作业之间的间隔"**。

这是一条可以在 PPT 上画出来的锯齿曲线：每次作业，暴露量归零。

**这就是这个产品的"PM2.5 时刻"**——空气污染在有 PM2.5 之前也只能说"今天有点呛"，指标出现之后，治理、定价、问责才全部成立。**我们做的是同一件事：给"地面对婴幼儿的危险程度"造一把尺。**

**三层指标体系**

**A 层 · 过程指标（现场 demo 就能产出）**

| 指标 | 说明 |
|---|---|
| 单次作业检出数 | 每次作业检出的 ≤31.7mm 物体件数。**这个数字以前根本不存在** |
| 盲区检出占比 | 其中多少件来自桌下/墙角等人眼盲区 → **直接量化"机器比人多看见了多少"** |
| 单次覆盖面积 / 耗时 | 可与人工巡查对照 |
| 漏检率 / 误检率 | 人工复核作为 ground truth |

**B 层 · 风险指标（产品的核心价值）**

| 指标 | 说明 |
|---|---|
| **IET 可吞入物暴露时长** | 主指标。作业频次决定其上限 |
| 日均暴露件次 | 一天内出现过的可吞入物总数 |
| 红色物暴露时长 | 最严重那一类（尖锐物 / 电池类）单独统计 |
| 高发区域热力 | 哪些位置反复出现 → 反过来指导家具摆放和家长告知 |

**C 层 · 经济指标（园长的账）**

| 项 | 怎么算 | 数据来源 |
|---|---|---|
| 时间成本 | 保育员每天地面排查用时 + 填巡查表用时 × 人力成本 | 现场实测（可做） |
| 风险成本 | 事故概率 × 单次损失 | 单次损失有公开判例锚（1.6 万 / 2.37 万 / 11.04 万 + 行政 + 招生损失）；**概率项无公开数据** |
| 招生收益 | "每日 AI 地面安检报告"进入招生话术与家长日报 | 可 A/B 测（有报告 vs 无报告的到访转化） |

> ⚠️ **诚实红线**：C 层的风险成本模型里，**事故概率项没有公开数据支撑**。PPT 上必须写成"**测算框架**"而不是"结论"，可以用机构自己的历史近似事件次数（"今年有几次孩子把东西放进嘴里被发现"）作为占位，并明确标注。**编一个概率数字是这份材料唯一可能翻车的地方。**

### 7.3 现场就能做的量化实验（同时是最好的营销素材）

**A/B 对照，30 分钟内可完成**：

1. 在测试区按真实活动室布置撒放 N 件道具（含 ≤31.7mm 与超限物，位置含明面与盲区）
2. **人工组**：一位队员（或现场邀请一位观众）用肉眼扫视 + 手动捡，记录用时与检出数
3. **机器组**：机器人作业，记录用时、检出数、盲区检出数
4. 输出对照表 + 那句话：**"人找到 5 件，机器找到 8 件，多出来的 3 件全在桌子底下。"**

这一条同时喂三个评分维度：原型完成度（20）、场景价值（20）、文档表达与营销创作（15）。**而且它是这场路演里唯一一个"有数字"的环节。**

## 八、红线

1. **不得做医疗诊断**（赛事规则明令）。口径只能是"物理危险物的识别、清除与记录"，**不得声称"预防窒息""降低死亡率"**。6896 例等数据仅作**场景价值背书**，不得宣称产品能改变这些数字。PPT 需有免责声明
2. **不得承诺法律效果**。只说"提供排查记录"，不说"帮您免责"
3. **不得声称可与幼儿同场作业**。这是产品边界，也是卖点
4. **感知能力诚实标注**：现有管线是 HSV 颜色+形状 / 模板匹配 / QR，**非开放词汇神经检测**。现场用**标准道具替代真实危险物**（尺寸预先量好），必须在 PPT 写明。官方规则明确允许合理模拟与降级演示，**主动说明扣的分远少于被问穿**
5. **31.7mm 的现场实现要留退路**：它是判据依据（讲得清），但深度相机估最长边的精度 36 小时内不保证。**建议：PPT 讲国标判据，现场用预先量好尺寸的标准道具，把尺寸估算做成"有则加分"**
6. **竞品数据进 PPT 前逐条核实**，写错比不写伤害大
