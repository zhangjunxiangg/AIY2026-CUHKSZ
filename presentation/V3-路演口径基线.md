## 2. 一句话定位 🔒

**电梯版（30 秒）**：
> 托育机构的园长每天必须巡查地面并留记录——这是法规压在他个人头上的义务，现在靠手工填表完成。
> 拾安是一台在孩子午睡、活动室没人的时候，自动把地上「能被塞进嘴里」的东西挑走，并留下一份带时间、位置、尺寸、照片的排查记录的机器人。
> 判据不是我们拍脑袋定的，是国标 GB 6675 的 31.7 毫米小零件阈值。

**一句话版**：
> **在孩子不在场的时间窗里，把地面风险挑走，并留下一份能举证的记录。**

**技术一句话版（回答"AI 用在哪"）**：
> 尺寸判据是国标（客观、写死），危险等级由 M-Claw 按当天口头交代的规则实时推理（运行时可变）。**把 LLM 删掉，"随当天在场儿童动态调整判定"这件事整个消失。**

## 3. 场景三要素 🔒

| | 冻结值 |
|---|---|
| **空间** | 托育机构 / 幼儿园的**活动室**（不是寝室）。小面积、多隔间、软质拼接地垫、低矮家具多 |
| **时间窗** | **午睡时段**（备选：入班前）。孩子在寝室，保育员必须在旁值守，活动室空置 1–2 小时且无人看管 |
| **触发** | 保育员进寝室前**口头交代当天规则** → 机器人作业 → 完成后日志推到她手机 |

**「只在孩子不在场时作业」是产品特性，不是免责条款。** 这一条同时解决合规、演示环境、评委第一质疑。

## 5. 问题陈述三层 🔒（路演"为什么做"的骨架）

**第一层 · 注意力不可分割** ✅ **口径已定（2026-08-05 23:xx）**
现场观察：10 分钟内保育员低头看地 **22 次**、抬头看孩子 **47 次**，切换 **7 次/分钟**。
→ **三个数字全部保留**，仍是第 2 页大字报主视觉。
→ **出处口径**：口播里半句话「**这是我们自己在活动室里数出来的**」+ 页脚小字「团队现场观察」。备选念法是连这半句都不说，只念数字、出处交给页脚。
→ ⛔ **禁止把这组数字说成出自任何报道或论文**。已核实：公开报道与文献均**不报告"每分钟注意力切换率"**这一指标（ECEC 眼动研究只报注视时长/注视次数），编一个来源等于给评委一个一问就穿的口子。
→ ⛔ **论文不上 slide、不进口播**（8/5 晚定：台上不提论文）。两篇已核对出处的真论文只放 `路演逐页文案.md` 的 Q&A 备用素材里，被追问"有没有依据"时才用：① Ukkonen-Mikkola et al. (2024), *Frontline Learning Research* 12(2), 70–98, DOI 10.14786/flr.v12i2.1153 —— 托小班（<3 岁）教师眼动眼镜研究，**教师看到自己注视数据时感到意外**；教师对注视行为的解释第一类是"**保护**"。② Duthois et al. (2025), *Early Childhood Research Quarterly* —— 50 名教师/250 名幼儿移动眼动，**教师注意力无法均匀分配，总有孩子被系统性漏掉**。

**第二层 · 人眼的物理极限**
致梗物就是地上最普通的东西：花生米、瓜子、豆类、笔帽、口哨、玩具零件。3 岁以下孩子的气道**只有铅笔粗细**。再加上桌下、墙角这些蹲下才看得见的盲区。
→ 口径：**这不是保育员不认真，是人做不到。**
→ ✅ **2026-08-05 23:xx 补强口径（v3 第 2 页收口句，替代原第三层的冷收口）**：**这不是保育员不认真——恰恰相反，她把注意力给了孩子，这是对的。被挤掉的那一部分是地面。我们要补的，就是这块被挤掉的注意力。** 产品定位是**弥补人因照顾孩子而必然产生的精力缺口**，不是指出谁没做到。

**第三层 · 没有证据（商业核心）** ⚠️ **v3 起不在第 2 页讲，移到第 6 页（记录回溯）与第 9 页（责任边界）**
《民法典》第 1199 条：无民事行为能力人在幼儿园受到人身损害，**先推定机构有过错**，机构能证明尽到教育、管理职责的才不承担责任。
→ 口径：**园方唯一的免责路径是证明自己排查过，而他手上只有一张事后补填的纸质巡查表。**
→ ⛔ **v3 删除的收口句**：~~"园长面对的不是地面不够干净，而是一个他无法证明自己尽责的风险敞口"~~ / ~~"不是地面不够干净，是没人证明得了自己尽责"~~ —— 太冷、且把话说成在指责机构。**这一层在第 6 页作为"我们给他一份原本拿不出的记录"出现，是解法的一部分，不是压人的话。**

## 6. 技术主轴四层 🔒（路演"怎么做的"的骨架）

**① 双机位感知 · 软总线**（对着 25 分最大单项）
- 辅助板 Gemini 335，架高侧位 = **哨兵**，专看盲区（桌下、墙角、机器人自身遮挡区）
- 小车板 Astra + 5DOF 臂 + 夹爪 = **执勤员**，过去、判断、夹走
- 软总线 = **对讲机**：发现 → 通报坐标 → 接单 → 处置 → 回报 → 出日志
- 代码实体：`src/perception/fusion_node.py`（双相机融合、盲区优先用辅助相机）

**② 危险判据国标化**（技术主轴）
GB 6675.2-2014：36 个月以下玩具严禁含可通过小零件试验器（**内径 ≤ 31.7 mm**）的部件。
→ **把"能被塞进嘴里"从一句感性描述，变成一个 31.7 毫米的国家强制标准阈值。**
→ 月龄分级也有标准依据：GB 6675-2025 按 **0–18 / 18–36 / 36–96 个月**三级差异化，低龄更严。**"危险随月龄变"不是我们编的产品逻辑，是国标本身的逻辑。**

**③ M-Claw 语义分级**（LLM 不可删除性）
判定 = **国标尺寸阈值（客观）× 当天口头规则（运行时可变）**
> 「今天托小班有个 1 岁半的新生，所有能塞进嘴的都按红色处理。」→ 同一个物体，等级立刻从黄变红，动作和播报跟着变。

**这是全案的记忆点，也是现场最容易出效果的 15 秒。演示视频必须收清这句话的音。**

**④ 物理清除 + 可举证日志**
夹走 → 分盒（红：立即通知 / 黄：待检 / 绿：留给常规清扫）→ 结构化记录：
```
14:32 | 活动室东南角地垫边缘 | 圆形金属物 φ≈20mm | 判定红色 | 已夹取至危险品盒 | 照片存档
```

## 7. 核心指标 IET 🔒

**可吞入物暴露时长（Ingestible Exposure Time）**
> 定义：一件符合 GB 6675 小零件判据（≤31.7mm）的物体，从落到地面到被清除之间的时长。

- 现在这个数字是**未知**——可能是几小时，直到有人偶然发现，或者孩子先发现了
- 有了机器人，它的**上限被硬性压到"两次作业之间的间隔"**
- 可视化：**锯齿曲线，每次作业归零**

**标准表述（照抄）**：
> 这就是这个产品的「PM2.5 时刻」。空气污染在有 PM2.5 之前也只能说"今天有点呛"；指标出现之后，治理、定价、问责才全部成立。**我们做的是同一件事：给"地面对婴幼儿的危险程度"造一把尺。**

**现场能产出的 A 层过程指标**：单次作业检出数 / **盲区检出占比** / 覆盖面积与耗时 / 漏检误检率（人工复核作 ground truth）。

## 8. 差异化一句话 🔒

> **它们把地上的东西当"清洁对象"或"通行障碍"，没有人把它当"风险证据"。**

| 玩家 | 它眼里地上的小东西 | 动作 |
|---|---|---|
| 普通扫地机 | 要吸走或绕开的**障碍** | 吸进尘盒（纽扣电池被吸进机器肚子）或避障绕开 |
| 石头 Z70 / 追觅 | 挡路的、清完要**归位**的杂物 | 标记 → 移开 → 扫地 → **放回原处**（对危险物而言，归位是有害的） |
| 商用清洁机器人 | 不在问题域 | 只处理小体积垃圾 |

**决定性细节（必须讲）**：石头的 OmniGrip 机械臂**默认停用，并配有紧急按钮和儿童锁**。
> **行业龙头对"儿童在场 + 会动的机械臂"的解法，是把这个功能锁掉。它不是没想到儿童场景，是主动把机械臂从儿童场景里撤了出来。这就是留给我们的空位。**

## 9. 责任边界声明 🔒（原文照抄进 PPT，这是产品的一部分）

```
作用范围：活动室地面
作用时间：14:00–14:20 的作业窗口
作用对象：地面可见的、最长边 ≤ 31.7mm 的物体
产出：该窗口内的完整排查记录（时间 + 位置 + 尺寸 + 照片 + 处置）
不负责：窗口之外、非地面、遮挡物之下、尺寸超限
```

**口径**：
> 我们不承诺"保证孩子不误吞"——那是无法兑现的，也正是所有厂商退缩的地方。
> 我们把责任切成一个窄到可以被验证的时间切片。**明确边界本身就是责任划分。**
> 对机构：它不接管你的责任，它给你一份你原本拿不出的证据。

**视觉红线（同等重要）**：
> ⛔ **所有生成图 / 实拍 / 视频里，机器人绝不能与儿童同框。** 出现一次就当场推翻 §3 和 §8——评委会立刻发现你的核心论点自相矛盾。
> ⛔ 不出现真实儿童面部（隐私）。
> ✅ 标准画面是：**空活动室、午睡时段、下午斜光、一台机器人独自作业。** 这个画面同时是合规的、on-message 的、而且更有电影感。

> ✅ **例外（2026-08-05 17:10 新增，18:20 扩大生产范围，23:55 定稿为单一视频，仅此一处）**：允许制作**一条**约 63 秒、**全程叠加"概念演示 · Concept Rendering"字幕角标**的 AI 生成概念宣传片（脚本 + 即梦操作手册见 `VID-AIGC-01-宣传片脚本.md`），同时用作独立提交/传播物料与路演**第 10 页**收尾（见 §14）。要求：
> ① 口播必须明说"这不是现场实拍"，不能让人误以为是真机拍摄；
> ② 儿童红线不因为是"概念演示"而放松——**仍然绝不能出现儿童**。⛔ **"孩子睡觉 / 老师照看"这类双轨镜头一律不拍**（2026-08-06 00:40 明确驳回）：一是它让"机器人不与儿童共处"这条边界变模糊，二是 AI 渲染幼儿面部手部翻车率极高。**改用"在场但不出镜"**：门缝暖光 / 门口一排小鞋 / 挂钩上的小外套 / 极轻的呼吸声底噪——情绪对比照样成立，红线一条没碰；
> ③ **夹爪口径（2026-08-06 00:40 收窄，非取消）**：✅ 允许夹爪与物体的**静态**微距（钳口张开悬停在物体上方，几乎不动）；⛔ **仍然禁止钳口合拢那一帧的动态渲染**——AI 在"钳口与小物体接触"时必崩（穿模、物体变形、多长出一片钳口）。**合拢发生在剪辑切点里**，由观众脑补；抓取的说服力靠"物体离地 + 地面空了"，不靠钳口。若 AI 反复失败，允许插入一段**真机实拍**的微距抓取，但该镜须单独标注"实拍片段"以与常驻的"概念演示"角标区分；
> ⑤ ⭐ **机器人形态必须锁回 `assets/robot-root-views/` 那台真实原型**（深灰阳极氧化铝、镂空板材、外露走线、麦克纳姆轮、立柱顶相机、五节臂+平口夹爪），**严禁美化成一体化成品外观，也严禁添加真机没有的硬件**（收纳仓/环形光带/投影/全息 UI）。**"愿景"体现在能力与场景，不体现在外形**——把原型画成另一台更漂亮的机器，评委的第一反应会是"这东西他们并没做出来"，直接反噬"原型完成度"这一项；
> ④ **除这一段收尾概念视频外，全片其余画面（尤其 V1 demo，见第 3 页）100% 必须是真实拍摄，这条例外不适用于任何"证明能力"的画面**——概念视频只用来"画一个愿景"，不能用来替代或混淆"这是我们做出来的东西"。

## 12. 诚实标注清单 🔒（主动说明，扣的分远少于被问穿）

必须在 PPT 和视频里主动声明的四条：

1. **道具替代**：现场用贴标签的标准道具（色块/圆片）替代真实危险物，尺寸预先量好。官方规则明确允许合理模拟与降级演示
2. **感知能力**：现有管线是 HSV 颜色+形状 / 模板匹配 / QR 解码，**非开放词汇神经检测**
3. **分工诚实**：**道具上的标签给出"这是什么"，M-Claw 负责"它对今天这个班危险吗"**——识别交给标签，判断交给模型。正好把 LLM 放在唯一不可替代的位置
4. **视频倍速**：机械臂动作慢，剪辑提速必须打 **"×N 倍速"** 字样
5. **隐私声明**：涉及环境图像"仅用于本次比赛演示，不存储真实环境数据"
6. **AI 工具声明**：赛事要求记录用了哪些 AI 工具、参与哪些环节、哪些内容 AI 辅助生成

**里程碑诚实边界**（现场实际能做到什么）：
| 故事里的动作 | 现场实际 | 状态 |
|---|---|---|
| 巡视地面 | 底盘按点位移动（`/cmd_vel` ≤0.20 m/s） | 可做 |
| 认出地上的东西 | HSV / 模板 / QR | 可做，非神经检测 |
| 看见盲区 | 双相机融合，盲区优先辅助板 | 队友已实现 |
| **判断危险等级** | M-Claw 按当天口头规则推理 | **核心，必须跑通** |
| 夹走 | 5DOF 臂 + 夹爪（ID10，250–800） | 可做，轻小物体 |
| 尺寸估算（31.7mm） | 深度相机估最长边 | ⚠️ **精度不保证。PPT 讲国标判据，现场用量好尺寸的道具，估算做成"有则加分"** |
| 生成日志 | 时间+类别+照片+处置 | 可做 |
