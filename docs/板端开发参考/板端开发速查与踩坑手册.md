## 1. 板子连接与 HDC

### 1.1 HDC 模式切换

| 模式 | 命令 | 说明 |
|---|---|---|
| USB 模式 | `hdc -t <connect-key> tmode usb` | 拔插 USB 自动识别，比赛时默认 |
| TCP 模式 | `hdc -t <connect-key> tmode port 5555` | 配合 `hdc tconn <IP>:5555` 网络连接 |
| 查看模式 | `hdc list targets -v` | 可看到 USB / TCP / UART 状态 |

**踩坑**：执行 `tmode port 5555` 后 daemon 会保持 TCP 模式；若板子未连网或未插 USB，`tmode usb` 会失败（`Not match target founded`）。必须先让板子通过 USB 或网络被识别，才能切换模式。

### 1.2 USB 连接排障

1. 确认板子已通电。
2. 使用 **USB 公对公数据线**（非充电线），插到板子 **OTG 口**。
3. 电脑端更换 USB-A 口，必要时换线。
4. `hdc list targets -v` 查看是否有 USB 设备出现。

### 1.3 文件推送路径规则

**踩坑**：`hdc file send` 在此版本上目标路径**不能带前导 `/`**，否则会被解析到本地磁盘。正确写法：

```bash
hdc -t <target> file send local_file data/local/robot/
```

错误写法：

```bash
hdc -t <target> file send local_file /data/local/robot/   # 会失败
```

### 1.4 一键部署脚本

`prep/deploy.sh` 已封装：先复制到扁平临时目录，再逐个 `hdc file send` 到 `data/local/robot/`，最后校验 YAML。用法：

```bash
bash prep/deploy.sh ec29004133314d38433031a523403c00
```

## 2. 运行时与环境变量

### 2.1 板端预装运行时

| 组件 | 路径 / 版本 | 验证状态 |
|---|---|---|
| Python | `/data/local/release/usr/bin/python3.12` | 【实测】 |
| Dora CLI | `dora-cli 0.3.12` | 【实测】 |
| ROS1 | 通过 `run` 包装器调用 | 【实测】 |
| M-Claw | 板端预装，API KEY 已配置 | 【已知】 |

### 2.2 Python 节点必须设置 LD_PRELOAD

**踩坑**：直接运行 Dora Python 节点会因缺少 `_Py_Dealloc` / `Py_DecRef` 符号崩溃。必须设置：

```bash
export LD_PRELOAD=/data/local/release/usr/lib/libpython3.12.so.1.0
```

在 Dora `dataflow.yml` 中每个 Python 节点都要加：

```yaml
env:
  LD_PRELOAD: /data/local/release/usr/lib/libpython3.12.so.1.0
  PYTHONUNBUFFERED: "1"
```

### 2.3 ROS1 使用 `run` 包装器

**踩坑**：不要直接用系统 `python3` 运行 ROS1 节点，会报 `libpython3.12.so` / `libintl.so` 找不到。正确方式：

```bash
run roscore &
run python3 talker.py &
run python3 listener.py
```

`run` 会自动设置 `PYTHONHOME`、`LD_LIBRARY_PATH`、`ROS_PACKAGE_PATH`。

## 3. Dora 数据流格式

### 3.1 节点输入事件

```python
{
    "type": "INPUT",              # 或 "STOP"
    "id": "dora/timer/millis/200",
    "value": pa.array([...]),     # pyarrow.Array
    "metadata": {"open_telemetry_context": b"..."}
}
```

定时器输入：
- `dora/timer/millis/200`：200ms tick，`value` 为 uint64 毫秒时间戳
- `dora/timer/millis/1000`：1s tick

### 3.2 节点输出 API

```python
node.send_output(
    "message",                  # dataflow.yml 中定义的 output id
    pa.array(["hello world"])   # 必须是 pyarrow.Array
)
```

### 3.3 常用命令

```bash
export LD_PRELOAD=/data/local/release/usr/lib/libpython3.12.so.1.0
export PATH=/data/local/release/usr/bin:/data/local/release/bin:$PATH
. /data/local/release/usr/setup.sh

dora up
dora start dataflow_hello.yml
dora list
dora check
dora stop <dataflow-uuid>
dora destroy
```

### 4.2 关键数据结构

#### `/scan`（LaserScan）

```yaml
header: { frame_id: "laser" }
angle_min: -3.1415927410125732
angle_max: 3.1415927410125732
angle_increment: 0.01745329238474369   # ~1°
range_min: 0.15000000596046448
range_max: 12.0
ranges: [float32 数组，约 360 点，inf 表示无返回]
intensities: [uint8 数组，有效返回约 13~15]
```

#### Astra 相机内参

```yaml
header: { frame_id: "astra_camera_color_optical_frame" }
height: 480
width: 640
distortion_model: "rational_polynomial"
K: [545.5231323242188, 0.0, 320.628173828125,
    0.0, 545.5231323242188, 239.10073852539062,
    0.0, 0.0, 1.0]
D: [0.11155129224061966, -0.18160298466682434, -0.0023391135036945343,
    0.0024356262292712927, -0.042575184255838394, 0.0, 0.0, 0.0]
```

**踩坑**：深度图 `D` 全为 0，当前驱动未启用深度畸变校正；RGB 有畸变。

#### `/odom`（Odometry）

```yaml
header: { frame_id: "odom" }
child_frame_id: "base_footprint"
pose: { position: {x,y,z}, orientation: {quaternion}, covariance: [...] }
twist: { linear: {x,y,z}, angular: {x,y,z}, covariance: [...] }
```

#### `/ros_robot_controller/imu_raw`（Imu）

```yaml
header: { frame_id: "imu_link" }
orientation: {x:0, y:0, z:0, w:0}   # 未融合
angular_velocity: {x: rad/s, y: rad/s, z: rad/s}
linear_acceleration: {x: m/s², y: m/s², z: m/s²}
```

#### `/ros_robot_controller/battery`（UInt16）

样本值 `12260`，推测为电压 mV（≈12.26V），量纲待确认。

#### `/servo_controllers/port_id_1/servo_states`（ServoStateList）

```yaml
servo_states:
  - {timestamp: 1609507137.488, id: 1, goal: 562, position: 562, error: 0, voltage: 9000}
  - {timestamp: 1609507137.509, id: 2, goal: 507, position: 507, error: 0, voltage: 9000}
  # ...
```

id 1-5 为 5 个机械臂关节舵机，id 10 为夹爪/旋转关节（待确认）。

#### `/cmd_vel`（Twist）

```yaml
linear: {x: m/s, y: m/s, z: 0}
angular: {x: 0, y: 0, z: rad/s}
```

安全限制（源码推断）：合速度 ≤ 0.20 m/s，角速度 ≤ 0.50 rad/s，单次时长 0.1–10.0 s。

#### FollowJointTrajectory Action

- 机械臂 Goal：`/arm_controller/follow_joint_trajectory/goal`
- 夹爪 Goal：`/gripper_controller/follow_joint_trajectory/goal`

```yaml
trajectory:
  joint_names: [joint1, joint2, joint3, joint4, joint5]   # 或 [r_joint]
  points:
    - positions: [rad...]
      velocities: [rad/s...]
      accelerations: [rad/s²...]
      time_from_start: {secs: 1, nsecs: 0}
```

## 6. 板上运行时启动顺序

官方脚本位于 `/data/robot-host/`：

1. `start-host-chassis.sh`：roscore + 底盘控制 + 里程计
2. `start-lidar-4.1.sh`：RPLIDAR `/scan`
3. `start-vision-4.1.sh`：Astra 深度相机
4. `start-arm-4.1.sh`：机械臂与夹爪控制器
5. `healthcheck-all-4.1.sh`：全链路自检

**踩坑**：3 号舵机若读取不到状态，需将其向上调整至直立或略朝上（指导老师建议）。

## 8. 开发启动检查清单

1. `hdc list targets -v` 确认板子在线（USB 或 TCP）。
2. 确认当前 HDC 模式（`hdc list targets`）。
3. 运行 `healthcheck-all-4.1.sh` 确认全链路。
4. Python 节点已设置 `LD_PRELOAD`。
5. ROS1 节点通过 `run` 启动。
6. 控制指令前确认机械臂在安全姿态，运动范围内无障碍。
7. 代码改动先提交 Git，再用 `prep/deploy.sh` 推送板端。
