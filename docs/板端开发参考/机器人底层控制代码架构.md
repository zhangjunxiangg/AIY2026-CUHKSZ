## 2. 核心模块详解

### 2.1 STM32 控制板 SDK（底盘/IMU/电池/按键）

**文件**：`vendor/kaihong-src/kaihong_adapter/robot-runtime/src/ros_robot_controller/src/ros_robot_controller/ros_robot_controller_sdk.py`

**功能**：封装与 STM32 控制板的串口通信协议。

**通信协议**：
```
0xAA 0x55 Length Function ID Data Checksum
```

**关键类：`Board`**

| 方法 | 功能 | 备注 |
|---|---|---|
| `set_motor_speed(speeds)` | 设置 4 个电机转速 | `[[1, rps], [2, rps], [3, rps], [4, rps]]` |
| `stop_motors()` | 停止所有电机 | 急停用 |
| `get_battery()` | 读取电池电压 | 返回 mV |
| `get_imu()` | 读取 IMU | 返回 `(ax, ay, az, gx, gy, gz)` |
| `get_button()` | 读取按键 | 返回按键事件 |
| `set_led()` / `set_buzzer()` | LED / 蜂鸣器 | 状态提示 |
| `set_oled_text()` | OLED 显示 | 板载小屏幕 |
| `bus_servo_*()` | 总线舵机控制 | 见 2.3 |
| `pwm_servo_*()` | PWM 舵机控制 | 4 路，板子上从里到外 1-4 |

**串口参数**：
- 设备：`/dev/ttyCH343USB0`（可通过 `RRC_DEVICE` 环境变量覆盖）
- 波特率：`1000000`（可通过 `RRC_BAUDRATE` 覆盖）

### 2.2 底盘运动学（麦克纳姆轮）

**文件**：`vendor/kaihong-src/kaihong_adapter/robot-runtime/src/chassis_controller/src/chassis_controller/kinematics.py`

**核心函数**：`calculate_wheel_rps(vx, vy, wz, ...)`

**参数**：
- `wheelbase=0.216` m（轴距）
- `track_width=0.195` m（轮距）
- `wheel_diameter=0.100` m（轮径）
- `max_linear=0.20` m/s（最大线速度）
- `max_angular=0.50` rad/s（最大角速度）
- `max_motor_rps=1.50` rps（电机最大转速）

**运动学公式**（4 轮麦轮）：
```python
vp = wz * (wheelbase + track_width) / 2.0
linear = [vx - vy - vp, vx + vy - vp,
          -vx - vy - vp, -vx + vy - vp]
rps = [value / (pi * wheel_diameter) for value in linear]
```

**控制节点**：`vendor/kaihong-src/kaihong_adapter/robot-runtime/src/chassis_controller/scripts/chassis_controller_node.py`

- 订阅：`/cmd_vel`（`geometry_msgs/Twist`）
- 发布：`/ros_robot_controller/set_motor`（`ros_robot_controller/MotorsState`）
- 超时保护：`cmd_timeout=0.50` s，超时自动停电机
- 发布频率：`20 Hz`

### 2.3 总线舵机驱动（机械臂 + 夹爪）

**文件**：`vendor/kaihong-src/kaihong_adapter/robot-runtime/src/servo_driver/src/servo_driver/servo_io.py`

**功能**：通过 ROS Service 与舵机通信。

**关键类：`ServoIO`**

| 方法 | 功能 |
|---|---|
| `get_position(servo_id)` | 读取舵机位置（0-1000） |
| `get_voltage(servo_id)` | 读取电压（mV） |
| `get_feedback(servo_id)` | 读取完整反馈（位置/目标/误差/电压） |
| `ping(servo_id)` | 检测舵机是否在线 |

**舵机 ID 分配**：
- ID 1-5：机械臂 5 个关节
- ID 10：夹爪

**SDK 中的关键命令**（`ros_robot_controller_sdk.py`）：

| 方法 | 命令字 | 功能 |
|---|---|---|
| `bus_servo_set_position(duration, positions)` | `0x01` | 设置位置 |
| `bus_servo_enable_torque(servo_id, enable)` | `0x0B/0x0C` | 扭矩开关 |
| `bus_servo_set_id(old, new)` | `0x10` | 修改 ID |
| `bus_servo_set_offset(servo_id, offset)` | `0x20` | 设置零点偏移 |
| `bus_servo_set_angle_limit(servo_id, [min,max])` | `0x30` | 设置角度限制 |
| `bus_servo_read_position(servo_id)` | `0x05` | 读位置 |
| `bus_servo_read_vin(servo_id)` | `0x07` | 读电压 |
| `bus_servo_read_temp(servo_id)` | `0x09` | 读温度 |

**重要修正（来自源码注释）**：
> 4.1 固件中 `0x0C` 是加载/保持，`0x0B` 是卸载。厂商原始 Python 映射写反了，导致"enable"实际上会释放机械臂关节。当前 SDK 已修正。

**夹爪控制示例**：`vendor/kaihong-src/kaihong_adapter/robot-runtime/set-gripper-position.py`
- 安全范围：`250-800`（但底层读到 ID10 上限是 `700`，建议不超过 700）
- 通过 `/servo_controllers/port_id_1/id_pos_dur` 话题发送 `RawIdPosDur` 消息

### 2.4 机械臂运动学

**正运动学（FK）**：`vendor/kaihong-src/kaihong_adapter/robot-runtime/host_arm/kinematics/src/kinematics/forward_kinematics.py`

- 5 自由度机械臂
- 连杆长度：`[0.23, 0.13, 0.13, 0.055, 0.117]` m
- 关节范围（度）：
  - J1: `[-120.2, 120.2]`
  - J2: `[-180.2, 0.2]`
  - J3: `[-120.2, 120.2]`
  - J4: `[-200.2, 20.2]`
  - J5: `[-120.2, 120.2]`

**逆运动学（IK）**：`vendor/kaihong-src/kaihong_adapter/robot-runtime/host_arm/kinematics/src/kinematics/inverse_kinematics.py`

- 解析解，非数值迭代
- `get_position_ik(x, y, z, roll, pitch, yaw)`：精确姿态
- `get_ik(position, pitch, pitch_range, resolution)`：俯仰角搜索

**注意**：FK/IK 是纯 Python 实现（替代了原来的 glibc/CPython 3.6 扩展），与 OpenHarmony Python 3.12 兼容。

### 2.5 轨迹执行控制器

**文件**：`vendor/kaihong-src/kaihong_adapter/robot-runtime/host_arm/servo_controllers/src/servo_controllers/joint_trajectory_action_controller.py`

**功能**：实现 `control_msgs/FollowJointTrajectoryAction` 接口。

**关键特性**：
- 更新率：`200 Hz`（控制循环），`20 Hz`（状态发布）
- 支持轨迹抢占（新轨迹来时终止当前轨迹）
- 支持路径约束和目标约束检查
- 将轨迹点转换为舵机原始位置值（`pos_rad_to_raw`）

**Action 接口**：
- 机械臂：`/arm_controller/follow_joint_trajectory`
- 夹爪：`/gripper_controller/follow_joint_trajectory`

## 4. 开发建议

### 4.1 不要重复造轮子

以下功能**已有底层实现**，直接调用 ROS 接口即可：
- 底盘运动控制（`/cmd_vel`）
- 舵机位置/状态读取
- 机械臂 FK/IK
- 轨迹执行（Action）
- 电池/IMU/按键读取

### 4.2 需要自行实现的部分

根据 `student/README.md`，参赛者需要自己实现：
- 比赛状态机
- 目标检测与识别
- 手眼标定（Astra 到机械臂）
- 抓取策略与执行逻辑
- 导航/路径规划（如果需要）

### 4.3 安全注意事项

1. **夹爪范围**：软件写 250-800，但底层实际读到上限 700，**不要超过 700**。
2. **扭矩开关**：`bus_servo_enable_torque` 的 0x0B/0x0C 已修正，不要再反转。
3. **底盘超时**：`cmd_vel` 超过 0.5s 无更新会自动停车，做演示时要持续发指令。
4. **舵机温度**：长时间运行注意舵机温度（当前夹爪 70℃ 偏高）。
