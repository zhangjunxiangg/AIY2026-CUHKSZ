## 1. 总体结论（先说对我们的三个验证）

1. **"智能体编排 + 技能注册表"是主流范式**：RoboBRIDGE、Pigey 等 2026 年新工作都在做"高层编排器调低层技能"，和我们 L5 智能体层 + skill 注册表的设计一致——答辩可直接引用
2. **模块化 pipeline 打败端到端**：Seg2Grasp、GRASP 都证明"检测→分割→抓取"的模块化组合在真实机器人上比端到端更稳、更快、可解释——支持我们"Dora 节点拼装"路线
3. **开放词汇检测 + RGB-D 点云 → 语言引导抓取**已被多篇真机验证，正是我们 B 方案（寻物）的技术路径

## 2. 智能体/编排层（对应 L5 M-Claw + L3 决策）

### ⭐ RoboBRIDGE：把 VLA 变成健壮机器人智能体的模块化编排框架
- arXiv: 2607.27881（2026-07）
- **输入模态**：视觉观测 + 语言指令 + 执行状态
- **输出模态**：动作（经技能原语执行）+ 失败恢复决策
- **架构**：Monitor（失败检测+分级恢复）/ Perceptor / Planner / Controller（技能原语+LoRA）/ Robot Interface 五模块
- **借鉴**：我们的 L1–L6 分层与它的模块划分几乎同构；它的"Monitor 失败恢复"就是我们降级预案的学术版——**答辩引用：证明分层架构是学界共识**

### ⭐ Physical Agency (Pigey)：闭环物理智能体编排器
- arXiv: 2607.21725（2026-07）
- **输入模态**：语言目标 + 低层观测反馈
- **输出模态**：子目标分解 + 技能/VLA 调用 + 结果验证
- **借鉴**：直接调"参数化技能"完成长任务，无需额外训练——**就是我们 M-Claw skill 注册表（move_to/grasp/detect/report）的完整理论支撑**；LIBERO-PRO 上把冻结策略从 12.8% 拉到 53.3%

### A Physical Agentic Loop for Language-Guided Grasping
- arXiv: 2604.07395（2026）
- **输入模态**：语言目标 + 执行状态证据（夹爪力度等连续信号）
- **输出模态**：抓取动作 + 执行中修正/恢复
- **借鉴**：把"执行状态监控"（对应我们 `joint_states` 待确认项）纳入 agent 环——抓没抓住要让 M-Claw 知道

### CoTinyVLA：0.9B 参数的 CoT 蒸馏 VLA
- arXiv: 2607.25487
- **输入模态**：双视角 16 历史帧 + 文本指令（带相机/时间标记）
- **输出模态**：episode 级 Plan（文本）+ chunk 级动作序列
- **借鉴**：episode Plan + chunk Think 两级输出——M-Claw 输出"计划文本"再转"动作块"的结构参考；小模型路线对 3588S 部署有参考价值

### TurboVLA：V+L→A 直映射实时 VLA（32Hz/0.9GB 显存）
- arXiv: 2607.27205
- **输入模态**：视觉 + 语言（独立编码后交互）
- **输出模态**：连续动作块（continuous action chunks）
- **借鉴**：边缘端 VLA 的可行性参考（未来拓展方向，36h 内不用）

## 3. 感知与抓取（对应 L2 感知层 + L1 控制层）

### ⭐⭐ Language-Guided Grasping under Partial Observation（巡检场景语言引导抓取）
- arXiv: 2603.07866（2026-03，腿式移动操作机器人，真机 9/10 成功）
- **输入模态**：操作员语言目标描述 + RGB-D（开放词汇检测 + 可提示分割 → 物体级点云 + 点云补全）
- **输出模态**：6-DoF 抓取位姿（带碰撞/可达性约束选择）
- **借鉴**：**与我们 B 方案（开放词汇寻物+夹取）场景最贴合的一篇**——"语言描述 → 开放词汇检测 → 点云 → 约束选抓"全链路，部分观测（看不清也抓）正好对应现场遮挡问题

### ⭐ GRASP (Bounding Boxes as Goals)：语言条件抓取的神经符号规划
- arXiv: 2606.12910（2026-06，真机 90 次试验 73.3% 成功，零任务训练）
- **输入模态**：自然语言查询 + 图像（VLM → 检测框）
- **输出模态**：神经符号目标状态（bbox 表达的目标）→ 执行
- **借鉴**："VLM 把语言翻译成检测框当目标"——轻量、零训练，**36h 黑客松可复现的路线**；支持抽象空间概念（"上层架子"）

### Seg2Grasp：模块化吸取式抓取
- arXiv: 2607.17757（2026-07）
- **输入模态**：RGB-D 图像
- **输出模态**：吸取点 + 开放词汇类别（Mask-CLIP）
- **借鉴**：分割→抓取→分类三段模块化，类无关 mask 生成——"先不管它是什么，先把它抠出来再识别"的两阶段思路

### Open-Vocabulary Part-Based Grasping (AnyPart)
- arXiv: 2406.05951（2024）
- **输入模态**：语言（指定部位）+ RGB-D
- **输出模态**：6-DoF 部位抓取位姿
- **借鉴**：抓"杯子的把手"这种部位级抓取——展示圈的加分项（若时间够）

### GaussianGrasper（高被引 120）
- 2024, IEEE RA-L
- **输入模态**：语言查询 + 多视角 RGB（3D 高斯泼溅语言场）
- **输出模态**：无碰撞抓取位姿候选
- **借鉴**：3D 语言场的参考（重，了解即可）

### Moto：移动操作的零样本交互感知导航
- arXiv: 2509.01658（2025）
- **输入模态**：视觉观测 + VLM 交互关键点
- **输出模态**：导航/接近动作
- **借鉴**：移动底盘接近目标物体时的"交互感知导航"——到底盘抓取距离怎么算

## 4. 场景记忆（对应 3.4 坐标系/场景理解）

### ⭐ Memory for Attention (VLMM)：语言条件下的重感知
- arXiv: 2607.23797（2026-07）
- **输入模态**：语言查询（"盯着什么"）+ 历史观测/行为标注地图
- **输出模态**：重感知调度决策（现在该重新看哪里）+ 地图更新
