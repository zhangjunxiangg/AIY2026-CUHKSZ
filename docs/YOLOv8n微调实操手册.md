# YOLOv8n 微调实操手册（算力 × 数据）

> 配套文档：《算法研究分工清单》第 3 章、《技术选型报告》§一.3
> 场景：AIY 2026 黑客松现场，闭集小类别检测（EVA 方块、小球、木圆柱、人形立牌、路锥）
> 训练机：队长笔记本 RTX 3050 Ti Laptop（4GB 显存）；部署端：RK3588S NPU（INT8 RKNN）

---

## 1. 算力：在哪训练？

**结论：队长笔记本本地训练即可，不需要云卡，绝不在板子上训练。**

| 项目 | 需求 | RTX 3050 Ti（4GB）实测预期 |
|---|---|---|
| 模型规模 | YOLOv8n，3.2M 参数，检测模型中门槛最低 | — |
| 显存 | 640px 输入、batch 8–16 约需 2–3.5GB | ✅ 刚好够，batch 别开大 |
| 训练时长 | 几百张图、50–100 epochs | 约 20–40 分钟 |
| 环境 | `pip install ultralytics`（自带 mosaic/翻转/亮度增广） | — |

**后备方案**：Google Colab 免费 T4（15GB），同样 20–40 分钟；本地环境装不顺时立即切换。

**转换也在笔记本上做**：`.pt` → ONNX → rknn-toolkit2 转 INT8（rknn-toolkit2 只能跑 x86），板端只负责推理。

---

## 2. 数据：要什么、要多少？

### 数量

| 项目 | 底线 | 稳妥 |
|---|---|---|
| 每类图片 | 50–150 张 | **200–300 张/类** |
| 5 类合计 | ~300 张 | ~1000 张 |
| 量化校准集（转 INT8 用） | 100–200 张代表性图片 | 从训练集里留 |

### 质量要求（比数量更重要）

- **必须现场实拍**：真实光照、真实场地背景，不要拿网图凑数
- 覆盖不同**距离 / 角度 / 高度**（俯视、平视、斜视）
- 包含**部分遮挡、画面角落目标**等难例
- 拍若干**不含目标的空场景**作负样本，降低误检
- 人形立牌、木圆柱颜色先验弱（HSV 兜不住），这两类多拍

### 标注

- 格式：YOLO txt（每图一个文件：`class x_center y_center w h`，归一化）
- 工具：X-AnyLabeling / LabelImg / Roboflow
- 提速：先用 COCO 预训练模型预标注，再人工修正，1–2 小时可标完
- 划分：8:1:1（训练/验证/测试）

## 3. 全链路流程（赛前必须预演一次）

```
现场采图 → 预标注+人工修 → 笔记本训练（30min）
        → 导出 ONNX → rknn-toolkit2 转 INT8 .rknn（留 100–200 张校准图）
        → 推到板端 NPU 推理 → HSV 兜底并联
```

**赛前准备动作**：用类似物体（彩色积木、纸杯、矿泉水瓶）在家把整条链路跑通一遍，现场只需要换数据重训。

---

## 4. 一句话总结

**每类 100–300 张现场实拍图 + 3050 Ti 半小时训练 + RKNN 转换 = 全部工作。**
