# 选题方向与场景策略研究：M-Claw × 软总线 × 驭系列底盘+夹爪

> 目的：回答四个问题——这套组合能干什么？为什么大家的作品会同质化？模型时代有什么独有设计？我们该往哪个方向走？
> 调查日期：2026-08-01。配套阅读：《AIY比赛认知.md》（评分标准）

---

## 1. 能力边界：这套组合到底能执行什么任务

**硬件**（比赛提供）：驭系列移动机器人（底盘 + 夹爪）+ KaihongBoard-3588S + 深度相机。
驭系列是深开鸿基于 M-Robots OS 的多形态机器人家族（移动机器人/四足狗/无人机），面向开发者，开放应用源码（[证券时报](https://stock.stockstar.com/KX2025052400015136.shtml)）。

**能力公式**：

```
能执行的任务 = 自主移动 + 轻小物体夹取/放置 + 深度视觉感知
             × M-Claw 语义理解（意图识别/任务拆解/策略生成/异常判断/解释反馈）
             × 软总线多设备协同（发现/共享/状态同步/跨设备任务流转）
```

落到具体动作词汇表：移动到点位、巡线巡逻、识别物体/标签/二维码、夹取轻小目标物、放到指定位置、避障、（经软总线）读写其他鸿蒙设备的状态、（经 M-Claw）听懂自然语言指令并自己拆步骤、用自然语言解释自己看到和做了什么。

**做不到/不要指望的**：重物抓取、灵巧操作（开瓶盖、按小按钮）、端侧大模型推理（NPU 只有 6 TOPS，视觉检测级别）、硬实时伺服闭环（底盘内部管，不开放给我们）。

## 2. 同质化的根因：大多数作品停留在"自动化时代的设计"

巡检、清洁、导览之所以千篇一律，是因为它们把 M-Claw 当**语音遥控器**用——"说一句话触发一个预设程序"。这不是模型时代的设计，只是给自动化脚本加了个语音开关。

| | 自动化时代的设计 | 模型时代的设计 |
|---|---|---|
| 编程对象 | 固定流程（if-then、状态机） | **意图**（自然语言描述目标，系统自行拆解） |
| 环境假设 | 结构化环境（磁条、工位、固定布置） | 非结构化/开放环境，机器去适应 |
| 感知结果 | 阈值告警（"检测到物体 ID 7"） | **语义理解**（"冰箱门没关，有安全隐患"） |
| 异常情况 | 遇到未预见情况就停 | 常识推理、协商澄清（"你是要这个还是那个？"） |
| 人机交互 | 按钮/示教器/触屏 | 自然语言多轮对话 + 主动解释 |
| 失败叙述 | 错误码 | "我为什么停下来"的自然语言说明 |
| 设计目标 | 消除变化（variance reduction） | 管理不确定性（uncertainty management） |
| LLM 的角色 | 没有，或只是语音开关 | 任务的理解者、拆解者、解释者 |

**同质化自检问题（赛题评审也会这么看）**："把 LLM 从这个设计里删掉，它还能成立吗？"——能成立，说明它是自动化作品穿了件 AI 外衣；不能成立，才是模型时代的原生设计。

## 3. 只有模型时代才成立的七类工程设计

1. **意图级任务编排**："把 A 点的箱子搬到 B 点，顺便看看走廊有没有异常" → M-Claw 拆成导航+巡检+搬运的复合任务图，而不是逐条写死
2. **开放词汇目标理解**："帮我找一盒蓝色包装的纸巾"——不限类别的语义检索，传统自动化做不到（检测器只能认训练过的类别）
3. **语义化异常判断**：不是"检测到物体"，而是"这个东西不该出现在这里"（理解场景常态与违规）
4. **可解释的执行**：机器人能用自然语言汇报"我在 3 号点位发现标签缺失，已拍照记录"——巡检报告自动生成
5. **多设备意图协同**：一句话让机器人、门口屏幕、指示灯自组织配合（软总线的正确打开方式：不是技术展示，是**意图的跨设备流转**）
6. **人机协商式执行**：指令模糊时主动反问澄清，执行中动态确认
7. **经验沉淀与复述**：任务结束后生成结构化记录（时间线+照片+语义描述），可检索可回放

## 4. 传感器感知 × LLM 语义理解：火花在哪里

两者的关系是互补升维：**感知给 LLM 眼睛（grounding），LLM 给感知脑子（语义）**。

```
深度相机 → 检测/定位（几何层："这里有个 30cm 高的物体"）
    → 语义场景图（认知层："这是一瓶放在配电箱旁边的易燃喷雾"）
    → M-Claw 推理（判断层："违规存放，需要记录并提醒"）
    → 动作+解释（执行层：拍照、上报、自然语言说明理由）
```

八个具体"火花"设计点（选型时往里装）：

1. 检测框 → 违规判断（"放错位置的东西"）
2. 场景常态建模 → 异常检测（"和昨天不一样的东西"）
3. 视觉属性描述 → 开放词汇检索（"蓝色的、方形的、在桌上的"）
4. 连续观察 → 事件理解（"有人摔倒了"而非"检测到人体"）
5. 环境事件 → 任务触发（"听到/看到异常 → 自主过去查看"）
6. 任务过程 → 自然语言叙事（边做边说，评委直接"听懂"演示）
7. 语义地图（"茶水间通常有杯子"）→ 更聪明的搜索路径
8. 多模态确认（看到+深度+标签三者交叉验证）→ 鲁棒的语义结论

## 6. 场景设计策略：要不要加道具和功能边界？——要，而且这就是胜负手

你的直觉是对的。开放命题不等于开放设计。**没有边界的场景一定做成同质化 demo**。理由和方法：

**为什么要主动设边界**：
1. 36 小时做不完一个"开放世界"——边界是完成度的前提（原型完成度 20 分）
2. 边界让"语义理解"成为刚需——场景里设计的每个意外，都是 M-Claw 的表演机会
3. 评委在统一测试区看 3 支队伍，记住的是"那个场景讲得最完整、最像真事的"

**三圈设计法**（道具与功能边界的落地方法）：

```
核心圈（必须 100% 跑通）：一条完整任务链 + 3-5 件关键道具
  例：3 个点位标识 + 1 个"违规物"（放错位置的瓶子）+ 1 个二维码标签
展示圈（计划内惊喜）：1-2 个现场即兴变量
  例：评委随口说"帮我找个蓝色的东西"→ 开放词汇检索当场响应
扩展圈（只讲不做）：画进 PPT 的 roadmap，证明可扩展性（安全扩展 10 分）
```

**道具清单设计原则**：每件道具都要回答"它给 M-Claw 或软总线创造了什么表现机会"。放不进去这个句子的道具，不要带。

## 7. 候选发展方向（按差异化程度排序）

### 方向 A：实验室/机房语义安全巡检员 ⭐推荐

- **场景**："深夜的实验室，机器人巡查：设备没关？物品放错位置？通道被堵？——它不只是看见，是看懂"
- **任务链**：接收"去巡一圈"指令 → 按点位巡检 → 发现"违规物"（预设道具：放错位置的易燃瓶/未关的设备模型/挡路箱子）→ 语义判断+拍照 → 自然语言生成巡检报告（读出来/发到屏幕）
- **M-Claw 结合**：违规判断（常识推理）、报告生成与解释；**软总线**：报告推送到第二块屏/另一台设备，或联动指示灯
- **市场背书**：巡检机器人国内破百亿、CAGR 15%+（§5）
- **同质化风险**：低——大多数巡检做的是"识别+报警"，我们做"理解+解释"
- **降级预案**：视觉识别不稳 → 二维码/标签辅助定位违规物；报告朗读改文字输出

### 方向 B：开放词汇寻物助手（"帮我找一下……"）⭐推荐

- **场景**：办公室/宿舍/仓库——"我的蓝色水杯呢？"机器人听懂描述、规划搜索路径、找到后夹取送回
- **任务链**：自然语言描述目标 → M-Claw 解析属性（颜色/形状/类别）→ 逐点位视觉检索 → 定位+夹取 → 送回并解释"它在 2 号桌的箱子后面"
- **M-Claw 结合**：开放词汇理解（自动化做不到的核心）、搜索策略生成；**软总线**：手机/另一设备下发指令与接收结果
- **市场背书**：商超/仓储是具身智能落地主战场（§5）；"找货"是仓储刚需
- **同质化风险**：低——"按描述找东西"和"按清单取货"是两代人
- **降级预案**：开放识别不稳 → 限定道具池（5 件可区分物品）；夹取失败 → 导航到人面前指引

### 方向 C：多设备协同智能前台（软总线的主场）

- **场景**：展厅/实验室门口——访客说"我想找张教授/参观实验室"，机器人理解意图，联动门口屏幕显示欢迎信息、点亮路径指示、引导到对应点位并讲解
- **任务链**：语音接待 → M-Claw 意图识别（找人/参观/登记）→ 软总线联动屏幕+灯光设备 → 引导移动 → 讲解 → 记录访客
- **软总线结合**：**最强**——多设备协同是评分示例链路的原文；M-Claw 负责人机对话与流程组织
- **市场背书**：商用服务机器人最大品类之一（导览接待）
- **同质化风险**：中高——导览是热门题，差异化全靠"软总线联动"这层做得是否实在
- **降级预案**：多设备不够 → 两块板互演（一块当环境设备）

### 方向 D：应急搜寻与现场语义回传

- **场景**：模拟灾后/停电实验室——"去看看里面什么情况"，机器人在障碍区搜索"被困者"（道具人偶/标识），回传"它在哪、周围什么状况、是否安全靠近"
- **M-Claw 结合**：现场状况的语义化描述与风险判断；**软总线**：实时回传外部指挥端
- **市场背书**：应急是官方参考选题，社会价值叙事强
- **同质化风险**：中——关键在于"语义化现场报告"而非"找到人"
- **降级预案**：全部可用模拟降级呈现，官方明确允许

### 方向 E：仓储/货架语义点检

- **场景**："盘点 3 排货架"——扫标签核对库存，并指出"这个东西放错了货架"（语义理解，不只是扫码）
- **与 A 的关系**：A 的工业变体；若团队更偏"实用/数据"叙事可选
- **同质化风险**：中（扫码点检常见，"放错"语义判断是差异点）

**建议组合**：**首选 A 或 B**（语义刚需最强、道具简单、闭环清晰），C 作为软总线表现力的补充元素揉进 A/B（比如巡检报告经软总线上屏）。
