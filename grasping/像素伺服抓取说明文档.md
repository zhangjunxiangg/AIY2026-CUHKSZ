## 1. 它做什么

仅使用**夹爪上方的 icSpring RGB 相机**（不用 Astra 深度、不依赖 URDF/手眼标定/IK），
输入**颜色（red/yellow/green）+ 形状（cylinder）**后自动抓取：

```
复位 → （找不到就底盘旋转扫描）→ 迭代逼近（每步：转车对准 → 判距离 → 前进）
→ 额外前进 5cm → 闭合 → 夹爪位置判定 → 夹住即抬升停止 →（可选放回）
```

```bash
ssh -p 2223 root@<板子IP>
cd /data/local/grasping
./grab red                 # 抓红色圆柱
./grab red --release       # 抓完放回
./stop_grasp               # 任何时刻安全停止（杀进程 + 底盘刹车）
```

## 2. 最终方案（实测迭代后的版本）

| 环节 | 实现 | 为什么 |
|---|---|---|
| 对准 | **底盘旋转**（CCW 为正，实测 +10° → u +233px，即 23.3px/deg） | J1 旋转会摇摆扫掠、且曾卡死；车转更稳 |
| 逼近 | 每个 iteration：质心 u 偏差 >15px 就转车 → v≥357 或 bbox 底边 ≥470 判到位 → 前进 15mm | 方向误差随时修正；v 触发保证"够近" |
| 深度补偿 | 触发后再前进 **5cm** | 标定像素是"确定能看到"的位置，不是"能抓住"的位置（实测差 4-5cm） |
| 夹持判定 | 闭合到 540 后连读 3 次夹爪位置：**位置稳定且 err ≤ -40 = 夹住**（空夹 err 只有 -14） | 图像判定不可靠（夹住时面积/位置变化无规律）；夹爪被物体撑住是最直接信号 |
| 夹住后 | 抬升 J2→300，**立即停止**，不做任何多余动作 | 用户要求 |
| 重试 | 未夹住 → 张开夹爪 → 转车重新对准 → 多走 20mm → 再夹（≤3 次） | 每次尝试都走完整的"对准→前进→夹"通用顺序 |
| J1 | **固定 500，全程不用** | 用户决策（搁置） |

## 5. 关键实测结论（踩坑沉淀）

| 发现 | 影响 |
|---|---|
| 相机无深度无内参 | 只能像素伺服 |
| J4=650 超出 FK/IK 有效域（`solution=False`） | 全链路不用 IK/FK |
| `/odom` 是 cmd_vel 开环积分 | **不能用来判断车是否真的动了** |
| 舵机有死区/回程差，J2 负重下垂 ~10 tick | 闭环一律以相机/夹爪读数为准，不信脉冲到位 |
| 迭代式 J1 伺服会"摇头"振荡 | 改底盘旋转 + 大步长少次数 |
| 夹爪 err：夹住 -80 ~ -84，空夹 -12 ~ -14 | 判定阈值 -40 |
| 相机设备号随 USB 重枚举漂移 | `start_camera.sh` 按名字解析自愈 |

## 7. 安全护栏（util_board 内置）

- 舵机脉冲 0-1000；单关节单次跳变 ≤120 tick（超出自动分步）；速度 ≤60 tick/s
- 夹爪 200-700，duration ≥1s
- 笛卡尔微动 ≤20mm/步；末端工作空间盒限制（出界拒绝，回程除外）
- 底盘直线 ±0.05 m/s、转向 ±0.4 rad/s，单次限幅限时长；`cmd_vel` 0.5s 超时自停
- 进程退出（含被 kill）自动刹车：`atexit` + SIGINT/SIGTERM 处理

## 8. 已知限制

- 转向增益 23.3px/deg 随距离变化（近距更大），迭代收敛即可，不追求一次到位
- 底盘旋转有打滑，转向到位精度 ±5°，靠每步复查修正
- 黄色/绿色目标未做端到端实测（检测已分别验证）
- HSV 阈值对光照敏感（`util_board.HSV_RANGES`，2026-08-05 实测校准）
