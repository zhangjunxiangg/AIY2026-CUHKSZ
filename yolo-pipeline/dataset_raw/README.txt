数据投放说明
============

把原始图片放在本目录（可含子目录），支持 .jpg/.jpeg/.png。

标注：每张图配同名 .txt（YOLO 格式，归一化坐标）：
  <class_id> <center_x> <center_y> <width> <height>
  - class_id: 0 = blue_cone（类别定义见 ../util_paths.py CLASSES）
  - 全部数值在 [0,1]
  - 一行一个目标；无目标的图片不建 .txt（当作背景图）

示例（img_001.jpg 里有一个锥桶，居中偏左）：
  img_001.txt 内容：
  0 0.312 0.548 0.086 0.215

数量建议：50-200 张（最少 30 张，01 步骤的硬门禁）。
采集要求：板端 Astra 相机 640x480 视角优先；多角度、多距离、多光照；
锥子需出现在白布场地区域内（比赛实际摆放位置）。
