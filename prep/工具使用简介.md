> 每个工具一段话讲清"干什么用 + 怎么启动 + 最常用命令"。详细命令见《M-Robots开发踩坑与参考库.md》。
> 更新日期：2026-08-01

## 1. HDC（开发机 ↔ 开发板的桥梁）⭐ 最常用

**干什么**：连开发板、进板子 shell、传文件、端口转发、看日志——相当于安卓的 adb。
**位置**：`D:\AIY-Hackathon\tools\hdc\`，已配 PATH。**注意：必须用安装后新开的终端**。

```bash
hdc version              # 验证安装（输出 Ver: 3.1.0e）
hdc list targets         # 看板子连上没有（每次操作前先看这个）
hdc shell                # 进板子 shell（进去后机器人命令都要加 run 前缀）
hdc file send 本地文件 /data/local/robot/    # 推代码上板
hdc file recv /data/log/faultlog/ ./logs/    # 从板子拉文件回来
hdc tconn 板子IP:5555    # 网络连接板子（摆脱 USB 线）
hdc fport tcp:5900 tcp:5900   # 端口转发（VNC/远程调试用）
hdc kill && hdc start    # 连不上时的万能重置
```

**配合板子的黄金组合**：`hdc shell` 进去 → `run python3 xxx.py` 跑节点 → 另开一个终端 `hdc shell` + `hilog -b d -p off` 看日志。

## 2. TightVNC Viewer（看 RViz 可视化界面）

**干什么**：板子上跑 RViz/rqt 等图形工具时，通过它远程看画面。
**启动**：双击 `D:\AIY-Hackathon\tools\vnc\tvnviewer.exe`（便携版，无需安装）。

**使用前提**（板子端先操作，详见踩坑库第 6 节）：
```bash
hdc shell → startxvfb → run x11vnc & → DISPLAY=:0 run rviz
```
然后二选一：
- USB 连接：电脑端 `hdc fport tcp:5900 tcp:5900`，VNC 里输 `localhost:5900`
- 网络连接：VNC 里直接输 `板子IP:5900`

黑屏排查：板子上 `pgrep -x Xvfb`、`pgrep -x x11vnc`。

## 3. VSCode（写代码 + 远程调试）

**干什么**：所有节点代码的编辑器；配合插件实现远程断点调试。
**已装关键插件**：

| 插件 | 什么时候用 |
|------|-----------|
| Python / Pylance | 写节点代码（补全、查错） |
| debugpy | **远程断点调试板子上跑的 Python**（黑客松最常用调试手段） |
| Remote-SSH | 如果连 Ubuntu 服务器/WSL2 编译才用 |
| C/C++ / rust-analyzer | 看/改 C++、Rust 代码（中间件层） |

**远程调试三步**（详细配置见踩坑库第 5 节）：
1. 板上：`run pip3 install debugpy`（只需一次）→ `run python3 -m debugpy --listen 0.0.0.0:5678 --wait-for-client /data/local/robot/xxx.py`
2. 本地项目建 `.vscode/launch.json`（模板在踩坑库）
3. 打断点 → F5

## 4. Git（代码备份的生命线）⭐ 老师点名要求

**干什么**：所有代码实时备份到 GitHub 比赛仓库——**板子挂了换备用板，15 分钟恢复全靠它**。
**赛中纪律**（对应任务 `44e50921`）：

```bash
git add -A && git commit -m "进展说明" && git push   # 至少每小时一次
```

- 新板恢复：`git clone 仓库` → `deploy.sh` 一键推上板
- 不确定的操作（reset/rebase）先问，别硬来

## 5. Python 3.12（本机脚本）

**干什么**：跑本机辅助脚本（数据处理、格式转换、批量推送等）。**注意与板上 Python 3.11 区分**——节点代码最终跑在板子上，本机 Python 只做辅助。

```bash
python 脚本.py                    # 直接跑
python -m venv .venv              # 需要装第三方包时先建虚拟环境
```
