## 环境来源

板端运行时由系统镜像预制，位于 `/data/local/release/usr/`。使用前需 source `/data/robot-host/robot-env.sh` 设置环境变量。

## 验证结果

| 项目 | 命令/路径 | 结果 |
|---|---|---|
| Python | `python3 --version` | 3.12.7 |
| ROS1 运行时 | `roscore` 状态 / ROS 话题列表 | ✅ 正常运行 |
| Dora | `/data/local/release/usr/bin/dora --version` | dora-cli 0.3.12 |
| 环境脚本 | `/data/robot-host/robot-env.sh` | 可正确设置 PYTHONPATH、ROS_PACKAGE_PATH 等 |

## 重要说明

- 板上 ROS 为厂商定制运行时，`rosversion -d` 返回 `<unknown>`，但 ROS1 话题与节点运行正常。
- 未找到 ROS2 / rclpy 环境，本次比赛主线使用 **ROS1 + Dora**。
- 环境激活方式：`source /data/robot-host/robot-env.sh`

## 使用示例

```sh
hdc shell
source /data/robot-host/robot-env.sh
roscore &
rosnode list
/data/local/release/usr/bin/dora --help
```
