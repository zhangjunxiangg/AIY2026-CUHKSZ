# 机器人本体与执行器控制方案

> 来源：官方机器车源码说明、M-Robots-OS 操作手册、板端实测（/data/robot-host 运行时）、healthcheck 与 rostopic 输出。  
> 状态：已上板验证传感器 dry-run；执行器接口以源码解析为主，未发送真实运动指令。

## 2. 执行器控制链路

### 2.1 底盘移动（麦克纳姆轮）

- **控制话题**：`/cmd_vel`
- **消息类型**：`geometry_msgs/Twist`
- **订阅节点**：`chassis_controller`（由 `start-host-chassis.sh` 启动）
- **速度限制**（来源 `mclaw-skill/scripts/ros_cmd_vel.py`）：
  - 合速度 ≤ 0.20 m/s
  - 角速度 ≤ 0.50 rad/s
  - 单次运动时长 0.1 ~ 10.0 s
- **安全建议**：运动结束后会自动发布 0.6~1.0 s 的零速；掉线 0.5 s 后底盘也会自动停止。
- **M-Claw 封装命令**：`robot_ops.py chassis-move --linear-x X --linear-y Y --angular-z Z --duration T`

### 2.2 机械臂

- **控制方式 1（单舵机）**：`robot_ops.py arm-set-one --servo-id N --position P`
  - 源码最终调用 `/data/robot-host/host_arm/scripts/arm_set_one.py`
  - 需设置 `ARM_HOST_ROOT=/data/robot-host/host_arm` 与对应 `PYTHONPATH/ROS_PACKAGE_PATH`
- **控制方式 2（轨迹）**：发布 `control_msgs/FollowJointTrajectoryAction` 到 `/arm_controller/follow_joint_trajectory/goal`
  - 当前状态反馈：`/arm_controller/state`
- **舵机状态**：`/servo_controllers/port_id_1/servo_states`
- **注意**：3 号舵机若读取不到状态，需将其向上调整至直立或略朝上（指导老师建议）。

### 2.3 夹爪

- **控制方式 1**：`robot_ops.py gripper-set --position P`
- **控制方式 2**：发布 `control_msgs/FollowJointTrajectoryAction` 到 `/gripper_controller/follow_joint_trajectory/goal`
- **状态反馈**：`/gripper_controller/state`

### 2.4 相机取图

- **M-Claw 封装**：`robot_ops.py camera-capture`
- 实际通过 Docker 容器 `rk3588s-vision` 中的 `camera_snapshot.py` 完成
- 输出到 `/data/local/tmp/.mclaw/output/robot/`

## 3. 板上运行时启动顺序

官方脚本位于 `/data/robot-host/`：

1. `start-host-chassis.sh`：启动 roscore、底盘控制、里程计节点
2. `start-lidar-4.1.sh`：启动 RPLIDAR `/scan`
3. `start-vision-4.1.sh`：启动 Astra 深度相机
4. `start-arm-4.1.sh`：启动机械臂与夹爪控制器
5. `healthcheck-all-4.1.sh`：全链路自检

## 4. 上层到执行器的调用关系

```
决策节点 / M-Claw Skill
    │
    ├─ chassis-move ──> ros_cmd_vel.py ──> /cmd_vel ──> chassis_controller
    ├─ arm-set-one ───> arm_set_one.py ──> /servo_controllers/port_id_1/...
    ├─ gripper-set ───> run-set-gripper-4.1.sh ──> /gripper_controller/...
    └─ camera-capture ─> camera_snapshot.py（Docker rk3588s-vision）
```

## 5. 关键结论

- 不需要直接操作 GPIO/PWM/CAN；机器人由官方运行时封装为 ROS 话题/Action。
- 底盘、机械臂、夹爪均通过标准 ROS 接口控制，上层可以用 Dora 节点或 M-Claw Skill 调用。
- 实际运动前建议先运行 `healthcheck-all-4.1.sh` 确认全链路正常。
