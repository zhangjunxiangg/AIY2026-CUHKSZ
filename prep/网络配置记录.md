## 1. WiFi 配置

| 项目 | 值 |
|---|---|
| WiFi 名称 | 手机热点（现场临时） |
| 板子 IP | `172.20.10.5` |
| 子网掩码 | `/28`（255.255.255.240） |
| 网关 | `172.20.10.0/28` |
| 连通性 | `ping 8.8.8.8` 通，`ping baidu.com` DNS 解析正常 |

**配置方式**：板端 `sta_test` 工具
```
选网卡 0 → 1 EnableWifi → 4 Scan → 5 GetScanResults → 15 ConnectToDevice → WPA-PSK 选 3 → DHCP 选 0 → 20 GetIpInfo
```

## 2. HDC 网络连接

| 项目 | 值 |
|---|---|
| 命令 | `hdc tconn 172.20.10.5:5555` |
| 状态 | 已验证可用 |
| 备注 | 执行 `hdc tmode port 5555` 后可用；已切回 `tmode usb` |

---

## 3. SSH 密钥认证

| 项目 | 值 |
|---|---|
| 端口 | `2223` |
| 用户 | `root` |
| 认证方式 | Ed25519 私钥 |
| 私钥位置 | `~/.ssh/id_ed25519`（开发机） |
| 板端授权 | `/var/empty/mclaw_authorized_keys` |

**连接命令**：
```bash
ssh -p 2223 -i ~/.ssh/id_ed25519 root@172.20.10.5
```

**队友接入**：私钥已分发到 `D:\AIY-Hackathon\ssh-keys\`，含 README 接入指南。

## 5. 现场网络建议

- 比赛现场建议带**便携路由器**，板子和开发机都连路由器，避免依赖会场 WiFi。
- 手机热点仅作备用，注意信号干扰和带宽限制。
- 若需多人同时开发，优先用 SSH + ROS 网络模式，不要共用 HDC USB。
