# 首次连板 Checklist（8/5 下午 · 现场照做）

> 目标：从"插上 USB"到"我的代码在板上跑起来"，再到"机器人能动、能抓"。
> 原则：**排障第一步永远是手动 `run python3` 跑一遍看报错**。

## 第 0 步 · 到场先问（全队一起，问导师/主办方）

- [ ] 两块板的开机/连接方式；小车板与机器人的连接关系
- [ ] 现场 WiFi 情况（要不要自带热点）
- [ ] 板端 `/data/robot-host/` 与我们手里的 `source code` 是否同版本
- [ ] 预录**动作组**有哪些（问有没有现成抓取动作序列）
- [ ] 软总线/M-DDS 怎么用（山茶主攻，我旁听）

## 第 1 步 · 连通板子（5 分钟）

```bash
hdc list targets          # ① USB 插上后先看这个：出现设备号 = 通了
hdc shell                 # ② 进板子（进去后提示符变了）
mount -o remount,rw /     # ③ 板内执行：根分区可写（写文件前必须）
```

连不上：`hdc kill && hdc start` 再试。

## 第 2 步 · 推一个测试文件跑通（10 分钟）

```bash
# Mac 上写一个 hello.py（print 一句英文，板上中文日志会乱码）
hdc file send hello.py /data/local/robot/
hdc shell
run python3 /data/local/robot/hello.py   # 看到输出 = 开发循环通了 ✅
```

## 第 3 步 · 摆脱 USB（可选但推荐）

```bash
hdc shell → sta_test      # 板内配 WiFi：1→4→5→15→20（详见踩坑库 §7）
ifconfig                  # 查板子 IP
hdc tconn <板子IP>:5555    # Mac 上执行，之后拔线也能操作
```

## 第 4 步 · 全队最高优先：验证机器人能动、能抓 ⭐（我的主战场）

用板上预装的 M-Claw（官方技能已封装安全限制，是最快的验货路径）：

```bash
hdc shell → run mclaw     # 启动 M-Claw（模型与密钥已预配好）
```

然后对它说（逐条，确认每条都有反应）：

- [ ] `返回底盘、雷达和机械臂状态` —— 整机自检
- [ ] `以 0.1 m/s 的速度向前移动 3 秒` —— **车动了** ✅
- [ ] 左右横移、原地旋转各一次（验证麦轮全向）
- [ ] `返回机械臂当前舵机值` —— 读到 ID1~5 + ID10 的反馈
- [ ] `把夹爪舵机 ID10 调整到 800`（张开）再 `调整到 300`（夹拢）—— **夹爪动了** ✅
- [ ] `返回雷达状态和一帧扫描检测值` —— /scan 有数据
- [ ] `用深度相机拍一张彩色图和深度图` —— Astra 有图

**任何一项不动 → 立刻记录现象并喊人**（30 分钟铁律；机器车问题线上问千笑老师）。

## 第 5 步 · 把验证结果回填

- [ ] 实测值填进《机器人控制对接文档.md》对应位置（舵机 ID ↔ 关节对应关系、夹爪实测开合值等）
- [ ] `learning`（本文档目录里的《学习记录.md》）记下今天跑通了什么
- [ ] **机械臂第一次动起来的瞬间录屏/拍照**（营销分素材！）
- [ ] `git add -A && git commit && git push`（2 小时一次纪律）

## 附 · 常用命令速查

| 场景 | 命令 |
|------|------|
| 看设备 | `hdc list targets` |
| 进板子 | `hdc shell` |
| 推文件上板 | `hdc file send 本地文件 /data/local/robot/` |
| 拉文件回 Mac | `hdc file recv /板上路径 ./` |
| 板上跑程序 | `run python3 xxx.py`（**run 前缀不能少**） |
| 看日志 | `hilog -b d -p off \| grep 关键字`（**另开干净 shell**） |
| 网络连板 | `hdc tconn <板子IP>:5555` |
| 端口转发（VNC 用） | `hdc fport tcp:5900 tcp:5900` |
| 连不上重置 | `hdc kill && hdc start` |
