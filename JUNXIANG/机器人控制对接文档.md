## 2. 接口清单

### 2.1 底盘（麦克纳姆轮全向）

| 项 | 值 | 来源 |
|----|----|------|
| 速度指令 | `/cmd_vel`（geometry_msgs/Twist） | ✅🟢 |
| 方向映射 | `linear.x` 前进+/后退−；`linear.y` 左移+/右移−；`angular.z` 左转+/右转− | ✅ |
| 安全硬限制 | 线速度 ≤ **0.20 m/s**；角速度 ≤ **0.50 rad/s**；时长 0.1–10 s | ✅（SKILL 安全规则） |
| **限速是节点参数级硬限** | 🟢 `chassis_controller_node.py _max_linear:=0.20 _max_angular:=0.50 _max_motor_rps:=1.50`——不是约定，是节点里卡死的 | 🟢 |
| **⚠️ 必须持续发布** | 🟢 三个节点均 `_cmd_timeout:=0.5`。**发一条 Twist 后 0.5s 会自动停**，前进必须是 **>2 Hz 的循环发布**（建议 10 Hz） | 🟢 |
| 停止方式 | 显式发 0；超时看门狗兜底（见上） | ✅🟢 |
| 相关节点 | `chassis_controller_node.py`、`cmd_vel_odom_node.py`（`_cmd_vel_topic:=/cmd_vel _odom_topic:=/odom`） | 🟢 |
| 官方调用示例 | `mclaw-skill/scripts/ros_cmd_vel.py` | ✅ |
| 实测修正系数 | linear_correction_factor = 🔬；angular_correction_factor = 🔬 | 待标定 |

> **对 `primitives.py` 的直接影响**：`move()` 不能写成"发一次 Twist 然后 sleep"，必须是 `while 未到时长: pub(twist); rate.sleep()`，退出时补发零速。
> **好消息**：这个超时机制天生是看门狗——进程崩了车自动停，属于**安全扩展 10 分的现成素材**。

### 2.9 板端接入方式 🟢

SSH 已打通，详见 **`JUNXIANG/板子SSH接入指南.md`**。要点：端口 **2223**（非 22）、**仅公钥认证**、私钥在 `~/.ssh/aiy_mrobots_ed25519`、**sshd 重启后不自启需手动拉起**。

非交互执行 ROS 命令的标准姿势（agent/脚本都用这个）：

```bash
ssh -p 2223 -i ~/.ssh/aiy_mrobots_ed25519 -o IdentitiesOnly=yes -o BatchMode=yes \
    root@172.20.10.5 'run rostopic list'
```

`run` 前缀不能省——ROS/Python 运行时靠它注入环境。

## 3. 动作原语设计（我的代码骨架）

```
primitives.py   # move() / stop_chassis() / arm_set_joint() / gripper() / scan_ik() / read_arm()
actions.py      # goto_point() / pick_and_place() / emergency_stop()（雷达哨兵）
control_node.py # 接待员主循环：收 C 的"目标位置" / E 的"任务指令" → 调 actions → 回报结果
```

- 起步抄改：`ros_cmd_vel.py`（动车）→ `set-gripper-position.py`（动夹）→ `check-target-ik.py`（问 IK）→ 综合参考 `automatic_pick.py`
- 场景参数模板：`student/scenario/scene-template.yaml`（抓取深度 0.60m、横向容差 18mm、稳定帧数等，直接参考）
- 每个组合动作统一模式：**做一步 → 检查 → 不对就安全退出（零速停车）**

**🟢 v1 新增的实现约束：**

1. `move()` **必须循环发布**（≥2 Hz，建议 10 Hz），不能发一次就 sleep —— 见 §2.1
2. 旋转优先用 IMU 闭环而非 odom 积分 —— 见 §2.2
3. 动臂前先 `arm-read`（初始化被关闭）—— 见 §2.3
4. 抓取动作组要自写，预留工时 —— 见 §2.7

## 4. 安全边界（安全扩展 10 分素材）

- [x] 厂家硬限制：速度 0.2 m/s / 0.5 rad/s / 单指令 ≤10s；舵机增量 >250 拒绝
- [x] 🟢 **节点级限速确证**：`_max_linear:=0.20 _max_angular:=0.50 _max_motor_rps:=1.50` 写死在 `chassis_controller_node.py`
- [x] 🟢 **指令超时看门狗**：`_cmd_timeout:=0.5`，控制进程崩溃/断连 0.5s 内底盘自动停 —— **这是可以直接写进路演材料的安全设计**
- [ ] 急停哨兵：雷达最小距离 < 🔬 cm → 立即发 cmd_vel 零速（不等任何指令），数据源 `/scan` ~13.7 Hz
- [ ] 🟢 硬件急停：订阅 `/ros_robot_controller/button` 做物理急停按钮
- [ ] 🟢 声光提示：急停时 `set_buzzer` 鸣笛 + `set_led` 变红，状态上 `set_oled`
- [ ] 机械臂动作前 `arm-read`，大动作分步（单步 ≤120 脉冲）
- [ ] 抓取失败/超时 → 手臂回安全位 + 底盘零速 + 上报失败原因
- [ ] 低压保护：`/ros_robot_controller/battery` < 🔬 mV 告警（满电 12604 mV 已知）
- [ ] 演示限速值：🔬（现场人密，压到多少待实测定）
