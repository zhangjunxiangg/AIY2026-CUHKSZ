### 2.4 运动学（IK）

| 项 | 值 | 来源 |
|----|----|------|
| 服务 | `/kinematics/set_pose_target`（interfaces/srv/SetRobotPose） | ✅ |
| 输入 | 目标 (x, y, z)（base_link 系）+ 俯仰角 pitch | ✅ |
| 输出 | success + 5 路舵机脉冲 + 当前脉冲；失败=不可达 | ✅ |

## 3. 动作原语设计（我的代码骨架）

```
primitives.py   # move() / stop_chassis() / arm_set_joint() / gripper() / scan_ik() / read_arm()
actions.py      # goto_point() / pick_and_place() / emergency_stop()（雷达哨兵）
control_node.py # 接待员主循环：收 C 的"目标位置" / E 的"任务指令" → 调 actions → 回报结果
```

- 起步抄改：`ros_cmd_vel.py`（动车）→ `set-gripper-position.py`（动夹）→ `check-target-ik.py`（问 IK）→ 综合参考 `automatic_pick.py`
- 场景参数模板：`student/scenario/scene-template.yaml`（抓取深度 0.60m、横向容差 18mm、稳定帧数等，直接参考）
- 每个组合动作统一模式：**做一步 → 检查 → 不对就安全退出（零速停车）**

## 4. 安全边界（安全扩展 10 分素材）

- [x] 厂家硬限制：速度 0.2 m/s / 0.5 rad/s / 单指令 ≤10s；舵机增量 >250 拒绝
- [ ] 急停哨兵：雷达最小距离 < 🔬 cm → 立即发 cmd_vel 零速（不等任何指令）
